# 텔레그램 리포트 형식 참고

## 형식

```text
어제의 today-menu
- 방문자 128명
- 메뉴 뽑기 버튼 누른 횟수 311번

오늘 할 일
- 추천 메뉴 후보에 비빔밥 추가하기
```

- 첫 줄은 제목이다. `-`로 시작하면 안 된다.
- 제목 아래에는 `- `(하이픈과 공백)으로 시작하는 줄이 하나 이상 온다.
- 빈 줄은 묶음 사이에서만 쓴다. 맨 앞, 제목 바로 아래, 맨 끝의 빈 줄은 무시한다.
- 한 줄에 의미 하나만 쓴다.
- 들여쓴 줄, `-`만 붙은 줄(`-줄`), 제목만 있는 묶음은 오류다.

## 키 위치

- 기본은 지금 프로젝트 폴더의 `./.env`다. 다른 곳이면 `TELEGRAM_ENV`에 경로를 적는다.
- 토큰 이름은 `TG_BOT_TOKEN` 또는 `TG_TOKEN`, 채팅 번호는 `TG_CHAT_ID`다.
- `.env`는 `.gitignore`에 넣는다. 스킬 폴더 안에 두지 않는다.

## 시험

```bash
printf '제목\n- 줄 하나\n' | ${CLAUDE_SKILL_DIR}/scripts/send.sh   # DRY_RUN 기본이라 화면에만 나온다
```

## 사람 몫

- 봇 만들기와 로그인(40장)
- 실제 전송을 켜는 일(`DRY_RUN=0`)과 보낼 채팅방을 정하는 일
