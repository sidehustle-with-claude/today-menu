# 텔레그램 리포트 보내기

1. 글을 `제목` 한 줄 + `- 줄` 여러 개로 만든다. 묶음이 여럿이면 빈 줄로 나누고 묶음마다 제목을 둔다.
2. `${CLAUDE_SKILL_DIR}/scripts/send.sh`에 글을 표준 입력으로 넘긴다.
3. 형식 오류가 나면 보내지 말고 오류를 그대로 알려 준다.
4. 키는 `.env`의 `TG_BOT_TOKEN`(또는 `TG_TOKEN`)과 `TG_CHAT_ID`를 쓴다. 값은 어디에도 적지 않는다.

## 하지 말 것
- 토큰이나 chat id를 SKILL.md, reference.md, 대화에 쓰지 않는다.
- 형식이 틀린 글을 고쳐서 몰래 보내지 않는다. 틀렸다고 알리고 멈춘다.
- 내 개인 채팅방 말고 다른 방으로 보내지 않는다.
- 실제 전송은 `.env`에 `DRY_RUN=0`이 있을 때만 된다. 클로드가 `DRY_RUN`을 바꾸지 않는다.

자세한 형식 규칙과 예시는 reference.md를 본다.

---
고친 이유: 빈 줄이 있는 리포트(54장 형식)도 오류로 막혀서, 빈 줄은 묶음 사이에서만 허용하도록 고쳤다.
