# /goal 과 /loop 고르기

## 한눈에

| 구분 | `/goal` | `/loop` |
| --- | --- | --- |
| 다음 턴의 시작 | 이전 턴이 끝나면 곧바로 | 정해진 시간이 지나면 |
| 끝나는 때 | 조건이 맞을 때 | 내가 멈추거나 7일이 지나거나 클로드가 끝났다고 판단 |
| 어울리는 일 | 끝이 분명한 큰 일 | 기다리며 확인하는 일, 상태 점검 |

## /loop 쓰는 법

| 적은 것 | 예 | 동작 |
| --- | --- | --- |
| 간격 + 프롬프트 | `/loop 5m check the deploy` | 고정 간격으로 실행 |
| 프롬프트만 | `/loop check the deploy` | 클로드가 매번 간격을 정함 |
| 간격만 또는 아무것도 | `/loop` | 내장 점검 프롬프트 또는 `.claude/loop.md` |

간격 단위는 `s`, `m`, `h`, `d`입니다. 초는 분 단위로 올림됩니다.

## 5분마다 배포 확인

```text
/loop 5m https://내-도메인.example 이 응답하는지 확인해.
정상이면 "정상"만 말해. 실패하면 이유를 두 줄로 쓰고 텔레그램으로 알려.
3번 연속 정상이면 반복을 끝내자고 알려 줘.
```

- 주소는 자리 표시입니다. 내 `today-menu` 주소로 바꿉니다.
- 정상이면 한 줄만 시킵니다. 출력이 길수록 반복마다 토큰이 늘어납니다.
- 끝 조건(연속 정상 횟수 또는 상한)을 처음부터 적습니다.

## 멈추기

| 종류 | 멈추는 법 |
| --- | --- |
| 스스로 정하는 간격 | 다음 반복을 기다리는 동안 `Esc` |
| 고정 간격(`/loop 5m`) | 클로드에게 "배포 확인 반복 취소해"라고 시킴 |

- 고정 간격 반복은 `Esc`나 `Ctrl+C`로 멈추지 않습니다.
- 취소하지 않으면 만든 지 7일 뒤 한 번 더 실행된 뒤 스스로 지워집니다.

## 한계

- 세션 안에서만 돕니다. 터미널을 닫으면 멈춥니다.
- 놓친 실행을 만회하지 않습니다.
- 한 세션에 예약은 최대 50개입니다.
- 컴퓨터가 꺼져도 돌아야 하는 일은 클라우드 예약(54장)이나 launchd로 옮깁니다.

## 토큰

- 반복마다 대화 전체를 다시 보냅니다. 간격이 짧을수록 한도가 빨리 줄어듭니다.
- `/usage`에서 반복 작업의 실행 횟수와 토큰을 봅니다.
- 반복 전에 `/clear`로 컨텍스트를 비우면 보내는 대화가 짧아집니다.

## 확인만 하는 반복은 스크립트로

"주소가 응답하는가"는 클로드가 판단할 일이 아닙니다. 스크립트가 하고, 이상이 있을 때만 클로드를 부릅니다.

```bash
scripts/check-deploy.sh https://내-도메인.example
```

- 정상이면 아무것도 출력하지 않고 종료 코드 0입니다.
- 응답이 200이 아니면 한 줄을 출력하고 종료 코드 1입니다.
- `NOTIFY=1`이면 `notify.sh`로 알림을 보냅니다. 실제 전송은 `.env`의 `DRY_RUN=0` 뒤에만 됩니다.
- launchd나 크론으로 5분마다 돌리는 법은 54장에서 다룹니다.

## .claude/loop.md

프롬프트 없이 `/loop`만 치면 이 파일이 기본 프롬프트가 됩니다. 명령줄에 프롬프트를 직접 쓰면 무시됩니다. 25,000바이트를 넘는 부분은 잘리니 짧게 씁니다.
