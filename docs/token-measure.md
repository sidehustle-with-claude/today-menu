# 토큰 실측 표

직접 재서 채웁니다. `claude -p --output-format json`의 결과에 `total_cost_usd`가 들어 있습니다.
이 표의 빈칸은 일부러 비워 둔 것입니다. 숫자를 지어서 넣지 않습니다.

| 일 | 클로드 호출 | 한 번 비용 | 한 달 비용 |
| --- | --- | --- | --- |
| 아침 리포트 | 하루 1회 | (직접 기록) | (직접 기록) |
| 데이터 수집 | 0회 | 0 | 0 |
| SNS 문구 만들기 | 하루 1회 | (직접 기록) | (직접 기록) |

## 재는 법

1. 클로드를 부르는 한 줄을 `claude -p --output-format json "..."`로 한 번 돌립니다.
2. 결과의 `total_cost_usd` 값을 "한 번 비용"에 적습니다.
3. 한 번 비용에 호출 횟수(하루 1회면 30)를 곱해 "한 달 비용"에 적습니다.
4. 구독 요금제에서는 `/usage`로 사용량이 얼마나 줄었는지도 같이 봅니다.

## 원칙

- 숫자를 모으고 보내는 일은 스크립트(토큰 0), 해석이 필요한 한 줄만 클로드가 합니다.
- 클로드는 `claude -p`로 한 번만 부르고 출력은 짧게 제한합니다.
