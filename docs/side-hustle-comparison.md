# 부업 네 가지 비교표

58장의 표를 그대로 옮긴 문서입니다. 돈과 수수료는 2026년 11월 기준이고, 가입 직전에 공식 주소에서 다시 확인합니다.
확인하지 못한 숫자는 지어내지 않고 `[확인 필요]`로 둡니다. 이 문서에는 수익 사례 숫자를 싣지 않습니다.

수익은 "내가 받은 돈에서 플랫폼 수수료와 쓴 돈을 뺀 것"입니다. 매출은 수수료를 떼기 전 받은 돈입니다.

- 수수료와 정책은 자주 바뀝니다. 가입 직전에 위 공식 주소에서 다시 봅니다.
- 콘텐츠 자동화의 수익 조건은 플랫폼마다 다르고 자주 바뀝니다. 계정을 열기 전에 그 플랫폼의 공식 수익 조건을 읽습니다.

## 길마다 읽을 장

- 웹 서비스: 11장 → 25장 → 32~36장 → 37·38장
- 앱: 11장 → 23·24장 → 39장 → 37·38장
- 게임: 13장 → 25장 → 38장
- 콘텐츠: 29장 → 46~48장 → 54장

여러 개를 동시에 하지 않습니다. 하나가 굴러가기 시작한 뒤에 다음으로 넘어갑니다.

## 하지 말 것

1. AI가 만든 결과물을 사람이 직접 한 서비스처럼 파는 것
2. 회사 업무와 겹치는 외주
3. 약관이 막는 자동화(보안문자 우회, 계정 대량 생성, 본인인증 우회)

로그인·본인인증·보안문자는 언제나 사람이 직접 합니다.
