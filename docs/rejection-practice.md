- today-menu에는 계정을 만드는 기능이 없습니다 (`mobile/src`에 로그인·회원가입 코드 없음).
- 그래서 이 메시지가 실제로 오면 먼저 "계정 생성 화면이 어디서 보였는지"를 심사팀에 되묻는 회신이 맞습니다.
- 계정 기능을 나중에 추가했다면 앱 안 삭제 화면과 웹 삭제 요청 링크를 먼저 만들어야 합니다 (구글 계정 삭제 정책).
