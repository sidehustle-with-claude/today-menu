# 개인정보처리방침

이 문서는 초안입니다. 상호, 대표자, 연락처는 예시 값이며, 공개하기 전에 직접 실제 값으로 바꾸고 법령 원문과 대조합니다.

## 1. 수집하는 항목

- 로그인 이메일 (이메일로 로그인할 때만)
- 즐겨찾기한 가게 번호
- 한 줄 취향 문장 (입력했을 때만)
- 언어 선택 (기기에 저장)
- 결제 정보: 주문 번호, 결제 금액, 결제 상태(프리미엄 이용권을 결제한 경우). 카드 번호는 받지 않고 결제 서비스 창에서 처리됩니다.
- 방문 통계: 방문한 페이지, 기기와 브라우저 종류, 대략적인 지역, 즐겨찾기 버튼을 누른 횟수와 메뉴 종류 (Google Analytics)

기기의 현재 위치는 받지 않습니다. 동네 이름은 이용자가 직접 입력하며 저장하지 않습니다.

## 2. 수집·이용 목적

- 로그인 이메일: 계정을 구분하고 로그인합니다.
- 즐겨찾기: 이용자가 저장한 가게 목록을 보여 줍니다.
- 한 줄 취향 문장: 문장을 메뉴와 조건으로 바꾸어 추천에 반영합니다.
- 언어 선택: 화면 언어를 기억합니다.
- 결제 정보: 결제를 처리하고 결제 여부를 확인합니다.
- 방문 통계: 어떤 페이지가 많이 쓰이는지 알아 서비스를 고치는 데 씁니다.

## 3. 보유·이용 기간

- 로그인 이메일과 서버에 저장한 즐겨찾기: 탈퇴하면 삭제합니다.
- 기기에 저장한 즐겨찾기와 언어 선택: 이용자가 브라우저 데이터를 지우면 사라집니다.
- 한 줄 취향 문장: 저장하지 않습니다.
- 주문·결제 기록: 보관 기간은 전자상거래 관련 법령을 원문으로 확인한 뒤 적습니다 [운영자 확인 필요: 법령 원문 확인 못 함].
- 방문 통계: Google Analytics 의 보존 설정을 따릅니다. 기간은 운영자가 설정한 값으로 이 문서에 적습니다 [운영자 확인 필요: 2개월 또는 14개월 중 선택].

## 4. 제3자 제공

이용자의 개인정보를 제3자에게 제공하지 않습니다. [운영자 확인 필요: 어느 쪽이 위탁이고 어느 쪽이 제공인지는 서비스 구조에 따라 달라서 법령 원문으로 판단합니다.]

## 5. 처리 위탁

| 맡기는 곳 | 맡기는 일 | 대상 정보 |
| --- | --- | --- |
| Supabase | 로그인과 즐겨찾기 저장 | 로그인 이메일, 즐겨찾기 |
| Cloudflare | 즐겨찾기 API 와 데이터베이스(D1) | 즐겨찾기 |
| Anthropic | 한 줄 취향 문장을 조건으로 바꾸는 AI 처리 | 한 줄 취향 문장 (이메일·전화번호는 보내기 전에 지웁니다) |
| 토스페이먼츠 | 결제 처리(결제창, 승인) | 주문 번호, 결제 금액, 결제 수단 정보(결제창에서 직접 입력) |
| Google | 방문 통계(Google Analytics) | 방문 페이지, 기기·브라우저 종류, 대략적인 지역, 이벤트 |

### 방문 통계와 거부 방법

- 방문 통계는 쿠키나 식별자를 써서 방문을 구분합니다.
- 이름, 이메일, 전화번호, 가게 이름은 통계로 보내지 않습니다.
- 브라우저에서 쿠키를 막거나 지우면 통계에서 빠집니다. 광고 차단 도구를 써도 빠집니다.
- 동의 배너가 필요한지는 지역과 사용 방식에 따라 달라서 이 문서가 판단하지 않습니다 [운영자 확인 필요: 개인정보보호위원회 안내와 법령 원문].

## 6. 파기

- 탈퇴 요청을 받으면 서버에 저장한 이메일과 즐겨찾기를 지웁니다.
- 기기에 저장한 정보는 이용자가 브라우저 데이터를 지워서 없앨 수 있습니다.
