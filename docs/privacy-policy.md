# 개인정보처리방침

이 문서는 초안입니다. 상호, 대표자, 연락처는 예시 값이며, 공개하기 전에 직접 실제 값으로 바꾸고 법령 원문과 대조합니다.

## 1. 수집하는 항목

- 로그인 이메일 (이메일로 로그인할 때만)
- 즐겨찾기한 가게 번호
- 한 줄 취향 문장 (입력했을 때만)
- 언어 선택 (기기에 저장)

기기의 현재 위치는 받지 않습니다. 동네 이름은 이용자가 직접 입력하며 저장하지 않습니다.

## 2. 수집·이용 목적

- 로그인 이메일: 계정을 구분하고 로그인합니다.
- 즐겨찾기: 이용자가 저장한 가게 목록을 보여 줍니다.
- 한 줄 취향 문장: 문장을 메뉴와 조건으로 바꾸어 추천에 반영합니다.
- 언어 선택: 화면 언어를 기억합니다.

## 3. 보유·이용 기간

- 로그인 이메일과 서버에 저장한 즐겨찾기: 탈퇴하면 삭제합니다.
- 기기에 저장한 즐겨찾기와 언어 선택: 이용자가 브라우저 데이터를 지우면 사라집니다.
- 한 줄 취향 문장: 저장하지 않습니다.

## 4. 제3자 제공

이용자의 개인정보를 제3자에게 제공하지 않습니다. [운영자 확인 필요: 어느 쪽이 위탁이고 어느 쪽이 제공인지는 서비스 구조에 따라 달라서 법령 원문으로 판단합니다.]

## 5. 처리 위탁

| 맡기는 곳 | 맡기는 일 | 대상 정보 |
| --- | --- | --- |
| Supabase | 로그인과 즐겨찾기 저장 | 로그인 이메일, 즐겨찾기 |
| Cloudflare | 즐겨찾기 API 와 데이터베이스(D1) | 즐겨찾기 |
| Anthropic | 한 줄 취향 문장을 조건으로 바꾸는 AI 처리 | 한 줄 취향 문장 (이메일·전화번호는 보내기 전에 지웁니다) |

## 6. 파기

- 탈퇴 요청을 받으면 서버에 저장한 이메일과 즐겨찾기를 지웁니다.
- 기기에 저장한 정보는 이용자가 브라우저 데이터를 지워서 없앨 수 있습니다.

## 7. 이용자 권리와 행사 방법
