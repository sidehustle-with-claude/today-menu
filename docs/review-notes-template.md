# 심사 메모 템플릿 (39장 39.6)

아래는 가짜 값입니다. 이 앱은 로그인이 없어서 데모 계정이 필요 없습니다. 로그인을 추가했다면 실제 계정 정보는 사람이 콘솔에 직접 입력하고, 이 파일에는 절대 적지 않습니다.

```text
심사 메모
- 앱 설명: 동네 이름을 입력하면 그 동네의 가상 예시 가게 중 오늘 먹을 곳 최대 3곳을 보여 줍니다.
- 로그인: 없음. 데모 계정이 필요 없습니다.
- 권한: 위치, 카메라, 사진 권한을 요청하지 않습니다.
- 광고: 홈 화면 하단에 구글 AdMob 배너가 있습니다. 처음 실행하면 동의 화면이 나올 수 있습니다.
- 확인 방법: 홈 화면에서 "망원동"을 입력하고 검색을 누르면 가게 카드가 나오고, 카드를 누르면 상세 화면이 열립니다.
- 설정: 홈 오른쪽 위 "설정"에서 개인정보처리방침과 문의 링크를 볼 수 있습니다.
- 새 기능: (이번 버전에서 바뀐 것을 구체적으로 적는다. 막연한 문구는 애플 2.3.1(a)에서 거절될 수 있음)
```

로그인이 있는 앱이면 아래 칸을 더합니다.

```text
- 데모 계정: reviewer@example.com
- 비밀번호: 여기에-심사용-비밀번호
```

## 규칙

- 실제 비밀번호를 이 저장소, 클로드 대화, 커밋에 넣지 않습니다.
- 새 기능은 화면 위치까지 구체적으로 씁니다.
