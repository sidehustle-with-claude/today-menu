# 취향 해석 API 비용 계산

비용은 곱셈입니다. (입력 토큰 x 입력 단가 + 출력 토큰 x 출력 단가) x 한 달 호출 수

## 단가 (100만 토큰당 달러, 2026년 11월 공식 가격 문서 기준)

| 모델 | API ID | 입력 | 출력 |
| --- | --- | --- | --- |
| Claude Haiku 5.5 | `claude-haiku-5-5` | 0.10 | 0.50 |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | 2 | 10 |
| Claude Opus 5.5 | `claude-opus-5-5` | 4 | 20 |

## 내 usage 숫자 (직접 채웁니다)

`src/parse-taste.ts` 가 호출마다 `usage` 를 찍습니다. 실제로 두 번 호출해 나온 숫자를 적습니다.

| 문장 | input_tokens | output_tokens |
| --- | --- | --- |
| 매운 거 말고, 혼밥 | | |
| 비 오는데 국물 있는 한식 | | |

## 월 비용 (책의 가정: 호출 1회에 입력 600, 출력 100 토큰)

| 모델 | 호출 1회 | 한 달 1만 건 | 한 달 10만 건 |
| --- | --- | --- | --- |
| Haiku 5.5 | 0.00011달러 | 1.1달러 | 11달러 |

계산: 600 x 0.10 / 1,000,000 + 100 x 0.50 / 1,000,000 = 0.00006 + 0.00005 = 0.00011

## 키와 상한

- 서비스마다 워크스페이스를 따로 만들고 그 안에서 키를 발급합니다 (사람 몫: 콘솔 가입, 결제 설정).
- 워크스페이스 또는 조직의 월 상한을 설정합니다 (사람 몫).
- 월 상한에 닿으면 429가 다음 달까지 계속 나옵니다. 무한 재시도하지 말고 코드 규칙(필터 버튼)으로 넘어갑니다.
- 호출 코드는 목업(`MOCK_LLM=1`)으로 먼저 확인하고, 실제 호출은 필요한 최소 횟수만 합니다.
