# 내가 고쳐 말한 버릇 추적하기

57장의 순서를 이 저장소의 스크립트로 정리한 문서입니다.

## 먼저 개인정보

- 세션 기록(`~/.claude/projects/<프로젝트>/<세션ID>.jsonl`)은 암호화되지 않은 평문입니다.
- 클로드가 `.env`를 읽었다면 비밀값도 기록에 남을 수 있습니다.
- 기록 파일을 저장소에 올리거나, 남에게 보내거나, 위키에 붙여 넣지 않습니다.
- 분석 결과로 남기는 것은 문장의 종류와 횟수뿐입니다. 원문은 남기지 않습니다.
- `my-messages.tsv`는 `.gitignore`에 들어 있습니다.

## 순서

1. 내 말만 뽑는다(토큰 0, 내 컴퓨터에서만 돈다).

```bash
python3 scripts/extract-my-messages.py                       # ~/.claude/projects 전체
python3 scripts/extract-my-messages.py --since 2026-10-27    # 이 날짜 이후만
python3 scripts/extract-my-messages.py --root fixtures/sessions --out /tmp/my-messages.tsv   # 가상 기록으로 시험
```

2. 신호별로 센다. 숫자만 나오고 문장 원문은 나오지 않습니다.

```bash
python3 scripts/count-corrections.py
```

3. 고쳐 말한 문장을 다섯 종류로 나눈다. 클로드에게 맡길 때는 원문 대신 익명화한 문장 100개만 넘깁니다.

| 종류 | 뜻 | 바로잡는 길 |
| --- | --- | --- |
| 형식 | 길이, 말투, 출력 모양을 고침 | `CLAUDE.md` 규칙, 말투 설정(5장) |
| 범위 | 일부만 하거나 시킨 것 밖을 건드림 | 요청 문장 습관, 체크리스트 |
| 검증 | 확인 없이 끝났다고 함 | 훅(8장), 하네스(51장) |
| 순서 | 먼저 물어보거나 엉뚱한 순서로 함 | 스킬(55장) |
| 사실 | 틀린 사실을 말함 | 위키(56장) |

4. 가장 많은 종류 하나만 규칙이나 훅으로 바꾼다. 한 번에 다 바꾸면 무엇이 효과였는지 모릅니다.

규칙은 "하지 마"보다 "이렇게 해"로 씁니다. 아래는 예시이고, 내 기록에서 가장 많은 종류에 맞는 것 하나만 `CLAUDE.md`에 넣습니다.

- 형식이 많다면: "답은 5줄 이내로, 제목 아래 `- 줄`로 쓴다."
- 검증이 많다면: "끝났다고 말하기 전에 `npm test`를 돌리고 결과를 보여 준다." (더 단단히는 51장 Stop 훅)
- 순서가 많다면: 55장처럼 스킬로 순서를 고정한다.
- 사실이 많다면: 56장 위키에 기록한다.

5. 일주일 뒤 같은 스크립트로 전후를 잰다. 규칙을 넣은 날을 적어 두고 기간을 나눠 두 번 돌립니다.

```bash
python3 scripts/count-corrections.py --until 2026-11-02   # 규칙을 넣기 전 (예시 날짜)
python3 scripts/count-corrections.py --since 2026-11-03   # 규칙을 넣은 뒤 (예시 날짜)
```

| 종류 | 고치기 전 주간 | 고친 뒤 주간 | 판단 |
| --- | --- | --- | --- |
| 형식 | (내가 센 횟수) | (내가 센 횟수) | 줄었으면 유지 |
| 검증 | (내가 센 횟수) | (내가 센 횟수) | 안 줄었으면 규칙을 훅으로 올림 |

- 빈칸은 직접 세어 채웁니다. 숫자를 지어서 넣지 않습니다.
- 줄지 않았다면 규칙이 너무 막연하거나 클로드가 읽지 못하는 자리에 있는 것입니다. 글 규칙으로 안 지켜지면 훅으로 강제합니다.

## 기록 파일 알아 둘 것

- 보관 기간은 `cleanupPeriodDays`가 정하고 기본은 30일입니다. 한 달에 한 번 분석한다면 기간 안에 합니다.
- 줄 구조는 Claude Code 내부용이고 버전마다 바뀔 수 있습니다. 스크립트는 필드가 없거나 줄이 깨져도 건너뜁니다.
- 어느 날부터 아무것도 못 뽑으면 한 줄을 열어 필드 이름을 확인하고 스크립트를 고칩니다. 그 한 줄에 개인정보가 없는지 먼저 봅니다.
- 도구 결과(`toolUseResult`)와 시스템이 넣은 줄(`isMeta`)은 내 말이 아니라서 뺍니다.
- 공식 길: `/export`, `claude -p --output-format json`, 훅의 `transcript_path`, Agent SDK, `/insights`.

## 사람 몫

- 기록에서 무엇을 남기고 무엇을 지울지, 결과를 어디까지 공유할지 정하는 일
- `claude purge`는 되돌릴 수 없으니 먼저 `--dry-run`으로 지워질 목록을 봅니다.
