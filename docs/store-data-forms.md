# 스토어 데이터 양식 답안 초안 (39장 39.5)

원본 표는 `docs/app-data-inventory.md`입니다. 이 문서는 그 표를 스토어 양식 모양으로 옮긴 초안이며, 최종 제출은 사람이 콘솔에서 합니다.

## 구글 Play 데이터 보안 양식

| 데이터 | 누가 모으나 | 공유 | 근거 |
|---|---|---|---|
| IP 주소 | 광고 SDK (AdMob) | 공유 | 구글 공식 Play 데이터 공개 문서 |
| 제품 상호작용 | 광고 SDK | 공유 | 같음 |
| 진단 정보 | 광고 SDK | 공유 | 같음 |
| 기기 또는 기타 ID | 광고 SDK | 공유 | 같음 |
| 입력한 동네 이름 | 앱 | 서버로 보내지 않음, 저장하지 않음 | `src/screens/HomeScreen.tsx`, `src/search.ts` |
| 계정, 이름, 이메일, 위치 | 모으지 않음 | - | 로그인·권한 코드 없음 |

- 데이터를 하나도 안 모아도 개인정보처리방침 링크는 내야 합니다.
- 광고 SDK가 모으는 항목도 내가 적어야 합니다.

## 애플 앱 개인정보 항목

- 광고 SDK가 쓰는 데이터 유형의 iOS 쪽 분류는 확인하지 못했습니다. 애플 App Privacy 문서와 AdMob 문서를 보고 사람이 맞춰 답합니다.
- 추적 허락 문구는 `mobile/app.json`의 `userTrackingUsageDescription`에 있습니다.

## 방침과 어긋나는지 보는 법

1. 개인정보처리방침 문서에 위 표의 모든 행이 있는지 봅니다.
2. 방침에 있는데 위 표에 없는 항목(예: 위치)이 있으면 방침을 고칩니다.
3. 코드에 새 SDK를 넣으면 이 표와 `docs/app-data-inventory.md`를 같이 고칩니다.
