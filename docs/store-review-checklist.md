# 제출 전 점검표 (39장)

기준 문서는 스토어 공식 원문입니다. 이 표는 2026년 11월에 공식 페이지에서 확인한 요지이며, 제출 직전에 원문을 다시 읽습니다.

- 애플: https://developer.apple.com/app-store/review/guidelines/
- 구글: https://support.google.com/googleplay/android-developer/topic/9858052

"코드 확인 결과"는 이 저장소의 `mobile/` 코드를 직접 찾아 본 결과입니다. 스토어 콘솔 안에서 하는 일은 "콘솔에서 확인"으로 둡니다.

## 확인하지 못한 것

- 심사 지침 원문 전체를 이 저장소 작업 중 다시 내려받아 대조하지는 않았습니다. 위 조문은 39장 본문이 인용한 것을 따릅니다.
- 광고 SDK가 모으는 항목의 iOS 쪽 분류와 지역별 동의 필수 여부는 확인하지 못했습니다 (`docs/app-data-inventory.md`).
