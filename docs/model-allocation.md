# 모델 배분

## 비교표 (직접 채웁니다)

같은 입력 10개(`data/taste-samples.json`)를 `npx tsx --env-file=.env scripts/compare.ts` 로 한 모델당 한 번만 돌립니다.
`taste-samples.json` 의 정답 필터는 초안입니다. 돌리기 전에 직접 읽고 고칩니다.

| 항목 | Claude Haiku 5.5 | Gemini Flash 계열 (무료) |
| --- | --- | --- |
| 정답 일치 (10개 중) | | |
| JSON 깨짐 (10개 중) | | |
| 평균 응답 시간 | | |
| 10건 비용 | | 0원 |
| 어려운 3개 결과 | | |

10건은 아주 작은 표본입니다. "어느 모델이 더 좋다"고 단정하지 않고, 내 입력 유형에서 쓸 만한지 감을 잡는 용도로 씁니다.

## 작업별 배분표

| 작업 | 맡길 곳 | 이유 |
| --- | --- | --- |
| 점수 계산, 필터링, 정렬 | 코드 (16장) | 늘 같은 답, 비용 0 |
| 애매한 취향 해석, 어려운 판단 | Claude | 틀리면 서비스 신뢰가 깨짐 |
| 대량의 단순 분류·정리 | 무료 API | 틀려도 피해가 작음, 양이 많음 |
| 이유 한 줄 쓰기 | 작은 모델 (Haiku) | 짧고 싸게 |
| 다국어 번역 (20장) | 상황별 | 법적 문구는 사람 검수 |

배분 기준은 두 가지입니다. 틀렸을 때 피해가 큰가, 입력에 개인정보가 섞이는가. 피해가 크면 Claude, 개인정보가 섞이면 무료 API 금지입니다.

## 한도에 닿았을 때

1. 같은 입력의 캐시 결과가 있으면 그것을 씁니다 (`src/cache.ts`).
2. 선호 공급자를 부르고, 실패하면 오류 종류를 봅니다.
3. 일시적 429 면 `retry-after` 만큼 한 번 기다려 다시 시도합니다.
4. 월 상한 오류(400, 429 `enforced_spend_limit_reached`)면 재시도하지 않고 코드 기반 추천으로 바꿉니다 (`src/recommend-safe.ts`).
5. 코드 기반 결과에는 "AI 설명 없이 기본 추천이에요"라고 표시합니다.
