## 읽는 법

- 기기 위치(GPS)는 받지 않습니다. 동네 이름을 사용자가 직접 입력합니다. 나중에 현재 위치 버튼을 넣으면 이 표와 처리방침을 먼저 고칩니다.
- 한 줄 취향에는 개인정보를 적지 말라고 입력창 아래에 안내합니다.
- 서비스 키(공공데이터, AI)는 서버 환경변수에만 있고 브라우저로 나가지 않습니다.
