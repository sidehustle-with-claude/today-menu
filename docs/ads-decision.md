38.2의 세 기준으로 적습니다. 내용은 내 서비스에 맞게 고치세요. 아래는 예시 답입니다.

| 기준 | 질문 | 내 답(예시) |
|---|---|---|
| 사용성 | 광고가 추천 카드를 가리거나 밀어내나 | 카드 목록 아래 한 곳에만 둔다. 높이 60을 미리 잡아 카드가 밀리지 않는다 |
| 방문자 규모 | 하루 방문이 얼마나 되나 (GA로 확인) | 아직 몇십 명 이하. 수익은 거의 없을 수 있다 |
| 결제와의 비교 | 광고 없애기 상품과 부딪치지 않나 | 결제가 없는 지금은 충돌 없음. 37장 이후 다시 본다 |

## 지키는 규칙

- 개발과 시험에는 구글 샘플 테스트 광고 단위만 쓴다 (`mobile/src/ads/adUnits.ts`).
- 실제 광고 단위는 `.env`(`mobile/.env.example` 참고)에만 두고 스토어 배포 빌드에서만 쓴다.
- 내 광고를 직접 누르지 않고, 가족·친구에게 눌러 달라고 하지 않는다. 무효 트래픽으로 계정이 정지될 수 있다.
- 광고를 켜면 개인정보처리방침과 스토어 데이터 양식에 광고 SDK를 적는다 (`docs/app-data-inventory.md`).
- 호스팅 플랜(웹)이 광고 사이트를 허용하는지는 25장의 기준으로 따로 확인한다.
