# AWS 안전 점검표 (28장)

항목만 적었습니다. 계정 번호, 이메일, 키는 이 파일에 쓰지 않습니다.
사람이 콘솔에서 직접 확인하고 체크합니다.

## 가입 직후 (서비스를 만들기 전에)

- [ ] 루트 사용자에 MFA(2단계 인증)가 켜져 있다
- [ ] 루트 사용자의 액세스 키가 없다
- [ ] 루트 비밀번호를 비밀번호 관리자에 보관했다
- [ ] 일상 작업용 관리자 사용자를 따로 만들었다 (그 사용자에도 MFA)
- [ ] 월 5달러 이하 비용 예산이 있다 (`infra/aws/budget-5usd.json` 참고)
- [ ] 알림이 두 개다: 실제 지출 80%, 예상 지출 100%
- [ ] 알림 이메일이 내 것이고 확인 메일을 눌렀다
- [ ] 무료 플랜인지 유료 플랜인지 가입 직후 화면에서 확인했다
- [ ] 리전을 한 곳으로 정했다 (콘솔 오른쪽 위와 CLI 설정이 같다)

## S3 버킷

- [ ] 버킷 이름이 `today-menu-test-` 뒤에 임의 숫자를 붙인 형태다
- [ ] 공개 접근 차단(Block Public Access) 네 가지가 모두 켜져 있다
- [ ] 계정 수준 공개 접근 차단도 켰다
- [ ] 사진을 공개해야 하면 버킷을 공개하지 않고 CloudFront + OAC를 쓴다 (이 책 실습 범위 밖)

## 권한

- [ ] 클로드용 사용자의 정책이 `infra/aws/policy-s3-upload.json` 모양이다 (PutObject, ListBucket만)
- [ ] 삭제(`DeleteObject`), 서버 종료, 정책 변경, 공개 설정 권한이 없다
- [ ] 필요하면 `infra/aws/policy-deny-destructive.json`을 보조로 붙였다
- [ ] 삭제 명령을 일부러 시켜 보고 `AccessDenied`로 거부되는 것을 확인했다
- [ ] 액세스 키는 코드·저장소·채팅에 없고 내 컴퓨터의 AWS 설정에만 있다
- [ ] `scripts/check-aws-keys.sh`를 돌려 키처럼 보이는 문자열이 없다
- [ ] 장기 액세스 키 대신 임시 자격 증명(`aws login`, IAM Identity Center)으로 옮길 계획을 적었다

## Lightsail 체험

- [ ] 서버를 만들기 전에 "30분 뒤 삭제 확인" 알림을 걸었다
- [ ] 만든 서버를 바로 지웠다
- [ ] 서버, 고정 IP, 스냅샷이 목록에 남아 있지 않다
- [ ] 며칠 뒤 Budgets와 청구 화면에서 요금이 없는 것을 확인했다
