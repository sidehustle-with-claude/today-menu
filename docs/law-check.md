# 법령 대조 기록

처리방침 초안(`docs/privacy-policy.md`)이 개인정보 보호법이 요구하는 항목을 빠뜨리지 않았는지 대조하는 표입니다.
이 저장소를 만들 때 법령 MCP 대조는 하지 않았습니다. 그래서 아래 조 번호와 링크 칸은 비워 두었고, 채우는 일은 독자가 합니다.

방법은 이렇습니다.

1. 법령 MCP 로 개인정보 보호법에서 처리방침에 들어가야 하는 항목을 원문으로 찾고, 조 번호와 law.go.kr 링크를 받습니다.
2. 받은 조 번호를 국가법령정보센터(https://www.law.go.kr)에서 직접 열어 조 제목과 내용이 같은지 봅니다.
3. 원문을 못 찾으면 "원문 확인 못 함"이라고 적습니다. 기억으로 조문을 쓰지 않습니다.

| 초안의 항목 | 원문 조 번호 | 원문 링크 | 확인 |
| --- | --- | --- | --- |
| 1. 수집하는 항목 | | | 원문 확인 못 함 |
| 2. 수집·이용 목적 | | | 원문 확인 못 함 |
| 3. 보유·이용 기간 | | | 원문 확인 못 함 |
| 4. 제3자 제공 | | | 원문 확인 못 함 |
| 5. 처리 위탁 | | | 원문 확인 못 함 |
| 6. 파기 | | | 원문 확인 못 함 |
| 7. 이용자 권리와 행사 방법 | | | 원문 확인 못 함 |
| 8. 문의처 | | | 원문 확인 못 함 |
| 9. 시행일 | | | 원문 확인 못 함 |

## 위치정보

이 서비스는 기기의 현재 위치(GPS)를 받지 않고 동네 이름을 사용자가 직접 입력합니다. 현재 위치 버튼을 넣게 되면 위치정보를 다루는 법의 대상이 되는지 원문과 감독 기관 안내로 먼저 확인합니다.

## 사람이 확정하는 부분

처리방침의 내용 확정과 게시 책임은 서비스 운영자인 본인에게 있습니다. 상호, 대표자, 연락처는 직접 입력합니다.
