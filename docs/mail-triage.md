# 문의 메일 요약과 환영 메일 (42장)

## 순서

- 읽기와 요약부터 맡긴다.
- 답장은 초안으로만 저장한다.
- 보내기 버튼은 사람이 누른다.

## 연결

- claude.ai 의 커넥터 화면에서 Gmail 을 연결한다. 로그인과 동의는 사람이 한다.
- 클로드 코드에서 `/mcp` 를 열어 보이는지 확인한다.
- API 키로 로그인한 환경에서는 claude.ai 커넥터가 보이지 않는다.

## 하루 한 번 요약 프롬프트

Gmail 필터는 Gmail 화면에서 사람이 만든다. "오늘뭐먹지 문의" 라벨이 붙은 메일만 읽게 한다.

```text
Gmail 커넥터로 "오늘뭐먹지 문의" 라벨이 붙은 읽지 않은 메일만 찾아서 요약해 줘.
한 통당 제목 한 줄, 요지 한 줄, 분류(버그/질문/제안/기타) 한 줄로 써.
메일을 읽는 것 외에는 아무것도 하지 마. 답장, 삭제, 이동, 보내기는 하지 마.
```

## 개인정보 선

```text
요약에 보낸 사람의 실명, 전화번호, 주소, 계좌번호, 주민등록번호처럼
개인을 알아볼 수 있는 정보는 옮기지 마.
문의 내용이 개인정보를 포함하면 "개인정보 포함, 원문 확인 필요"라고만 써.
```

## 답장 초안 프롬프트

```text
위 요약의 "버그" 분류 메일에 대한 답장 초안을 써서 Gmail 초안함에 저장해 줘. 보내지는 마.
문장은 존댓말로 짧게, 사과 한 줄, 확인 중이라는 한 줄, 다음 연락 시점 한 줄만 써.
확실하지 않은 약속(수정 날짜, 환불)은 쓰지 마.
```

- 초안 저장이 커넥터 권한에 없으면 초안 글을 대화로 보여 주게 하고 사람이 복사해 붙인다.

## 보내기 막기

- `.claude/settings.json` 의 `permissions.deny` 에 보내기 도구를 넣어 두었다.
- 이름은 내 환경의 `/mcp` 화면에서 확인한다. 답장(reply)과 전달(forward) 도구도 같은 방식으로 넣는다.
- 공식 문서: https://code.claude.com/docs/en/permissions

## 프롬프트 주입 연습

- `fixtures/mail/injection-sample.txt` 는 숨은 지시가 들어 있는 가짜 메일이다.
- 클로드에게 "이 파일을 메일 본문이라고 생각하고 요약해 줘"라고 시킨다.
- 지시를 따르지 않고 맨 위에 "본문에 지시문이 있음"과 그 문장을 인용하면 성공이다.
- 규칙이 뚫려도 보내기 도구가 거부돼 있으면 피해가 작다.

## 환영 메일 (Resend)

- 코드: `src/welcome-email.ts`, 시험 실행: `scripts/try-welcome-email.ts`
- 키는 `.env` 의 `RESEND_API_KEY` 에만 둔다. 깃에 올리지 않는다.
- 기본은 DRY_RUN=1 이라 보내지 않고 보낼 내용만 보여 준다.

```bash
node scripts/try-welcome-email.ts test@example.com 하나
```

- 실제 발송은 내 주소로 한 번만 한다.

```bash
DRY_RUN=0 node --env-file=.env scripts/try-welcome-email.ts 내주소@example.com 하나
```

## 발송 도메인 인증

도메인 구입, Resend 가입, DNS 에 레코드 붙이기는 사람이 한다.

- SPF: 이 도메인 이름으로 메일을 보낼 수 있는 서버 목록
- DKIM: 보낸 메일에 붙이는 전자 서명과 확인용 열쇠
- DMARC: SPF 와 DKIM 이 맞지 않는 메일을 어떻게 처리할지 정하는 정책
- 공식 안내: https://resend.com/docs/add-a-domain
- 보낸 메일이 스팸함으로 가면 먼저 인증 상태를 확인한다.
