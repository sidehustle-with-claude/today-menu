# 배경음악 사용 기록과 출처 표기 (48장)

법률 조언이 아닙니다. 요금과 약관은 바뀝니다. 쓰기 전에 원문을 직접 읽습니다.
- Suno 이용 약관: https://suno.com/terms
- Suno 요금: https://suno.com/pricing

## 쓰기 전 확인

- [ ] 약관 원문을 읽고 내 용도(앱 소개 영상을 SNS 에 올림)가 허용되는지 확인했다
- [ ] 무료 요금제 곡은 비상업용으로만 쓴다
- [ ] 상업용 영상은 유료 구독 중에 새로 만든 곡을 쓴다 (무료일 때 만든 곡을 나중에 유료로 바꿔도 상업용이 되는지는 약관에 직접 적혀 있지 않다)
- [ ] 리믹스는 요금제와 상관없이 비상업적 목적으로만 쓴다
- [ ] 곡을 만든 기록을 아래 표에 남겼다

## 곡을 만든 기록

곡마다 한 줄씩, 생성 화면 캡처와 함께 보관합니다. 저작권 신고(자동 오탐 포함)가 왔을 때 내 곡이라는 근거가 됩니다.

| 날짜 | 요금제 상태 | 설명 글 | 곡 이름 | 쓴 영상 | 생성 화면 캡처 파일 |
|---|---|---|---|---|---|
| (적기) | (무료 / 유료 구독 중) | (docs/music-prompts.md 의 번호) | (적기) | (적기) | (적기) |

## 출처 표기

Suno 약관은 곡에 출처 표시를 요구하지 않습니다(작성 시점 기준). 그래도 밝히는 습관을 둡니다.

```text
배경음악: Suno 로 만듦
```

- 영상 설명란이나 블로그 글 끝에 한 줄로 넣는다.
- 다른 곳에서 가져온 음원은 곡마다 출처 표시 조건이 다르다. 곡별 라이선스 표시를 읽는다.

## 저작권 신고가 왔을 때

1. 신고 내용을 읽고 어떤 곡과 비슷하다고 하는지 본다.
2. 내가 만든 곡이면 이의 신청을 한다. 가만히 두면 신고가 그대로 유지된다. (유튜브 스튜디오 > 콘텐츠 > 신고 > 조치 취하기 > 이의 제기)
3. 위 기록 표와 캡처를 보관해 둔다.
4. 급하면 그 곡을 빼고 다른 음악으로 바꿔 다시 올린다.
5. 필요한 권리가 확실할 때만 이의 제기한다. 반복하거나 악의적이면 불이익이 있고, 한 번 낸 이의 제기는 취소할 수 없다.
6. 출처를 밝혔거나 수익을 켜지 않았다는 이유는 사유가 되지 않는다.
- 공식 안내: https://support.google.com/youtube/answer/2797454

## 무료 대안

각 사이트는 곡마다 이용 조건이 다릅니다. 곡별 라이선스 표시를 확인합니다.

- YouTube 오디오 라이브러리: https://support.google.com/youtube/answer/3376882
- Pixabay Music: https://pixabay.com/service/license-summary/
- Free Music Archive: https://freemusicarchive.org/faq (CC 의 NC 는 상업 이용 불가, BY 는 출처 표시 필요)
