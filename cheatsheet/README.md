# 부록 E 치트시트

요금제: Pro로 충분

자주 쓰는 명령과 클로드에게 시킬 말을 한 곳에 모았어요. 본문에서 실제로 쓴 것만 넣었고, 이름은 공식 문서(https://code.claude.com/docs)에서 확인했습니다. 2026년 11월 기준, Claude Code 2.1.316입니다.

읽는 법
- 장 번호는 그 명령이 본문에 나오는 곳이에요. 앞의 번호가 설명이 가장 자세합니다.
- 내 버전에서 명령이 없다고 나오면 `claude update` 로 새 버전을 받으세요.
- 명령 이름이나 동작이 바뀌었다면 공식 문서가 맞습니다.

## 이 폴더의 파일

- [commands.md](commands.md): 슬래시 명령, 단축키, 터미널 명령
- [prompts.md](prompts.md): 상황별로 클로드에게 시킬 말 모음

치트시트에도 같은 원칙을 한 번 더 적어 둡니다. 로그인, 본인인증과 문자 인증번호, 보안문자, 결제, 약관 동의는 클로드에게 시키지 않고 내가 직접 해요.
