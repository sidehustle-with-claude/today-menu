# 부록 E 치트시트: 명령

## 슬래시 명령

슬래시 명령은 클로드 코드 안에서 `/` 로 시작해 치는 명령이에요. 메시지 맨 앞에 써야 먹습니다.

### 시작하고 끝내기

| 명령 | 하는 일 | 장 |
|---|---|---|
| `/help` | 도움말과 명령 목록 | 2 |
| `/login` | 계정에 로그인 (사람 몫) | 2, 41, 43 |
| `/exit` | 클로드 코드 끝내기 | 2 |
| `/status` | 버전, 모델, 계정, 연결 상태 | 10 |
| `/doctor` | 설치와 설정 점검 | 4 |

### 대화와 기억 관리

| 명령 | 하는 일 | 장 |
|---|---|---|
| `/clear` | 새 대화 시작, 컨텍스트 비우기 | 2, 10 |
| `/compact` | 지금까지 대화를 요약해 컨텍스트 확보 | 10 |
| `/context` | 컨텍스트가 얼마나 찼는지 보기 | 4, 10 |
| `/resume` | 이전 대화로 돌아가기 | 10, 50 |
| `/rename` | 세션에 이름 붙이기 | 10, 50 |
| `/export` | 대화를 글자 파일로 내보내기 | 57 |
| `/insights` | 최근 세션을 분석한 보고서 만들기 | 10, 57 |

## 단축키

| 키 | 하는 일 | 장 |
|---|---|---|
| `Esc` | 클로드가 하던 일 멈추기. 지금까지 한 일은 남아요 | 2, 10 |
| `Esc` 두 번 | 입력이 있으면 입력 지우기, 비었으면 되돌리기 메뉴 열기 | 2 |
| `Shift+Tab` | 권한 모드 돌려 바꾸기. 계획 모드도 여기 있어요 | 10, 51 |
| `Ctrl+O` | 대화 기록 화면 열기. 목표 평가 이유도 여기서 보여요 | 52 |

## 터미널 명령

터미널에서 `claude` 뒤에 붙여 치는 명령이에요.

| 명령 | 하는 일 | 장 |
|---|---|---|
| `claude` | 대화 시작 | 2 |
| `claude --version` | 내 버전 보기 | 2, 5 |
| `claude update` | 새 버전으로 올리기 | 2, 5 |
| `claude doctor` | 설치 상태 점검 | 2 |
| `claude -c` | 이 폴더의 가장 최근 대화 이어가기 | 2 |
| `claude -p "질문"` | 대화창 없이 한 번 묻고 끝내기 | 15, 45, 52, 54, 57 |
| `claude --model opus` | 모델을 정해 시작 | 9 |
| `claude --effort high` | 생각 강도를 정해 시작 | 9 |
| `claude --permission-mode plan` | 계획 모드로 시작 | 51, 52 |
| `claude --worktree 이름` | 작업 복사본을 따로 만들어 시작 | 50 |
| `claude --chrome` | Chrome 연동을 켜고 시작 | 13, 14, 43 |
| `claude --debug-file 경로` | 문제 확인용 기록을 파일로 남기며 시작 | 8 |
| `claude mcp add` | MCP 서버 추가 | 7, 42 |
| `claude mcp list` | 붙인 MCP 서버 보기 | 7, 18 |
| `claude remote-control` | 폰에서 이어 쓸 세션 열기 | 41 |
| `claude purge` | 저장된 세션 기록 지우기 | 57 |

> 주의
> `claude purge` 는 기록을 지웁니다. 57장을 읽고 무엇이 지워지는지 확인한 뒤에 쓰세요.
