# 레퍼런스

같은 분야 서비스의 공개 첫 화면 5~10곳을 모아 두는 폴더입니다.

## 모으는 법

- 로그인하지 않고 열리는 첫 화면만 캡처합니다. 가입이나 결제 화면은 열지 않습니다.
- 캡처는 `서비스이름-날짜.png` 로 저장하고, 아래 표에 주소와 날짜를 적습니다.
- 값을 뽑은 결과는 `values.md` 에 적습니다.

## 이 저장소에서는

- 다른 서비스의 화면 캡처는 저작권이 있어서 저장소에 올리지 않았습니다. 폴더 구조와 표 형식만 남겼습니다.
- 내 컴퓨터에서 캡처를 모으면 `references/*.png` 는 Git에 올리지 않게 `.gitignore` 에 넣어 둡니다.
