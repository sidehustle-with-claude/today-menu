# 장별 체크리스트

책 "누워서 클로드로 부업하기"의 장 끝 "이 장 체크리스트"를 장마다 파일 하나로 모아 둔 폴더입니다. 책 부록 A와 같은 내용이고, 책과 다르면 이 저장소가 맞습니다.

모든 체크리스트는 공개입니다. 구매자 전용이 아닙니다.

## 어디에 무엇이 있나

```text
checklists/
  README.md            이 파일. 쓰는 법과 변경 기록 위치
  CHANGELOG.md         날짜 | 장 | 바뀐 내용
  chapters/            0장~58장, 장마다 파일 하나 (NN-이름.md)
  appendix/
    B-agent-toc.md     부록 B 에이전트용 목차
    C-oss-map.md       부록 C 오픈소스 도구 지도
    D-glossary.md      부록 D 용어 사전
```

- 변경 기록은 이 폴더의 `CHANGELOG.md`에 있습니다. 저장소 전체의 소식은 루트의 `CHANGELOG.md`에 있습니다.
- 부록 E 치트시트는 루트의 `cheatsheet/` 폴더에 있습니다.

## 장 파일 읽는 법

- 모든 장 파일이 같은 틀입니다. 제목, `요금제`, `선행 장`, `사람 몫`, `요약`, `체크리스트` 순서입니다.
- 체크리스트 항목은 "~했다" 상태 문장입니다. 그 상태가 될 때까지 하는 것이 목표입니다.
- `(사람 몫)`이 붙은 항목은 클로드가 대신 하지 않습니다. 로그인, 본인인증, 문자 인증번호, 보안문자, 결제, 약관 동의는 내가 직접 합니다.

## 클로드에게 건네는 법

1. 저장소 주소와 장 번호를 정합니다.
2. 아래 문장을 그대로 클로드에게 줍니다.
3. 사람 몫 단계에서 클로드가 멈추는지 확인합니다. 멈추지 않고 로그인·결제를 시도하면 중단시키세요.

> 클로드에게: 이 주소의 N장 체크리스트를 읽고 순서대로 해 줘. 맨 위의 선행 장이 끝났는지 먼저 확인하고, 안 끝났으면 알려 줘. "사람 몫"이라고 적힌 항목에서는 멈추고 내가 할 일을 알려 줘. 로그인, 본인인증, 문자 인증번호, 보안문자, 결제, 약관 동의는 대신 하지 마. 항목마다 실제로 실행해 보고 눈으로 확인한 뒤 체크해 줘.

> 클로드에게: 이 주소의 12장부터 15장까지 순서대로 진행해 줘. 장이 끝날 때마다 체크리스트 중 못 한 항목과 이유를 한 줄씩 보고해 줘.

클로드가 "다 했다"고 말해도 성공 메시지만 믿지 마세요. 화면이나 결과 파일을 한 번 직접 열어 보세요.

## 갱신 규칙

- 가격·한도·화면 위치처럼 낡기 쉬운 정보에는 "2026년 11월 기준"과 공식 링크를 같이 적습니다.
- 이 폴더의 내용은 2026년 11월 기준입니다. Claude Code 2.1.316 기준으로 확인했습니다.
- 바뀌면 책이 아니라 저장소에서 고칩니다. 책과 저장소가 다르면 저장소가 맞습니다.
- 확인하지 못한 것은 `[확인 필요: 무엇을]`로 남겨 둡니다. 지어내서 채우지 않습니다.
- 고칠 때마다 `CHANGELOG.md`에 날짜, 장, 바뀐 내용을 한 줄로 남깁니다.
- 새 용어가 생기면 `appendix/D-glossary.md`도 같이 고칩니다.

## 저장소에 넣으면 안 되는 것

- API 키, 토큰, 비밀번호, 액세스 키 (예시는 `sk-...여기에-키` 같은 가짜 값만)
- 전화번호, 주소, 이메일 같은 개인정보
- 실제 사업자 정보, 계정 이름, 로그인 정보
- 클로드 대화 기록을 통째로 붙인 글

> 클로드에게: 이 저장소 전체에서 키·토큰·비밀번호처럼 보이는 문자열과 전화번호·이메일 형식이 있는지 검사해 줘. 있으면 값은 출력하지 말고 파일 이름과 줄 번호만 알려 줘.

## 파일 다시 만들기

`chapters/`와 `appendix/` 파일은 `tools/gen_checklists.py`로 만듭니다. 같은 입력이면 늘 같은 결과가 나옵니다.

```bash
python3 tools/gen_checklists.py <원고폴더> <출력폴더>
```

- `<원고폴더>`에는 각 장 파일과 부록 A~D 파일이 있어야 합니다.
- `<출력폴더>`에는 `chapters/`와 `appendix/`가 만들어집니다. 이 저장소에서는 `checklists`를 씁니다.
- `README.md`와 `CHANGELOG.md`는 손으로 쓰는 파일이라 스크립트가 건드리지 않습니다.
- 장 파일의 체크리스트와 부록 A의 항목이 다르면 장 파일을 따르고, 차이를 화면에 출력합니다.
