## 43장 chromectl로 웹 콘솔 작업 맡기기
요금제: Pro로 충분
선행 장: 4, 41
사람 몫: 로그인·문자 인증·본인인증·보안문자·결제 인증
요약
- 웹 콘솔에서 매번 같은 칸을 채우는 반복 작업을 클로드에게 맡기고, 제출 직전까지만 시키는 방법을 익힙니다.
- 화면을 보며 클릭하는 방식과 스크립트로 반복하는 방식의 차이를 알고, 한 번 해 본 조작을 스크립트로 저장합니다.
- 로그인 화면이 나오면 멈추게 하는 규칙과, 삭제·결제는 누르지 않게 하는 안전장치를 세웁니다.
체크리스트
- [ ] 맡기려는 사이트의 이용약관에서 자동화 허용 여부를 확인했다
- [ ] 크롬에서 내가 직접 로그인했다
- [ ] `claude --chrome`으로 시작하고 `/chrome`에서 상태가 Enabled다
- [ ] CLAUDE.md에 로그인 시 멈춤, 삭제·결제 금지, 허용 도메인을 적었다
- [ ] 제출 버튼 앞에서 멈추게 시켰고, 화면을 내가 확인했다
- [ ] 반복 조작은 스크립트로 저장했고 값과 키는 코드에 없다
- [ ] 일부러 로그아웃해서 클로드가 멈추는지 시험했다
