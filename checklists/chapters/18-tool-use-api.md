## 18장 LLM이 기존 API를 골라 부르게 하기: 툴 사용으로 서비스 만들기
요금제: Pro로 충분
선행 장: 16, 17
사람 몫: 공공데이터포털 가입·활용 신청 동의
요약
- 툴 사용의 원리를 설명할 수 있습니다. LLM은 실행하지 않고, 무엇을 부를지만 고릅니다.
- 공공데이터 API 두 개(날씨, 음식점)를 툴로 정의하고, "비 오는 날 혼밥 메뉴" 질문에 LLM이 알아서 부르게 만듭니다.
- 가게 정보를 지어내지 않게 막고, 같은 툴을 MCP로 감싸 클로드 코드에서도 씁니다.
체크리스트
- [ ] 공공데이터포털 활용 신청을 마쳤고 키가 `.env`의 `DATA_GO_KR_KEY`에 있다 (사람 몫)
- [ ] 캡처를 책이나 글에 올릴 때 인증키 값은 가렸다
- [ ] `get_weather`, `get_places` 툴 설명에 "돌려주지 않는 정보"가 적혀 있다
- [ ] 첫 응답 원본을 `samples/`에 저장했다
- [ ] 루프에 `maxTurns`가 있다
- [ ] 툴 실패 시 `is_error: true`와 다음 행동을 담은 문장을 돌려준다
- [ ] "영업시간 알려 줘" 같은 질문 10개로 "정보 없음" 응답을 확인했다
- [ ] 툴 결과에서 필요한 필드만 추려 돌려준다
- [ ] MCP 서버를 등록하고 `claude mcp list`에서 연결을 확인했다
- [ ] 화면 하단에 공공데이터 출처 표시를 넣었다
