## 28장 AWS는 언제 쓰나: 무료 서비스로 부족해질 때
요금제: Pro로 충분
선행 장: 3, 25, 26, 27
사람 몫: 가입·MFA·카드·IAM 키 발급·서버 삭제
요약
- Vercel·Cloudflare·Supabase와 AWS가 어떻게 다른지, AWS를 써야 하는 경우와 안 써도 되는 경우를 가려낼 수 있습니다.
- 가입 직후 예산 알림을 걸고, 루트 계정을 쓰지 않으며, 권한을 최소로 주는 순서를 익힙니다.
- 클로드에게 AWS를 맡길 때 삭제·종료 권한은 주지 않는 방법을 알게 됩니다.
체크리스트
- [ ] 루트 사용자에 MFA가 켜져 있고 액세스 키는 없다
- [ ] 월 5달러 이하 비용 예산과 80%·100% 알림을 만들고 확인 메일을 눌렀다
- [ ] 일상용 사용자를 따로 만들었다
- [ ] 버킷의 공개 접근 차단이 모두 켜져 있다
- [ ] 업로드와 목록 권한만 가진 정책을 붙였고 삭제 권한이 없다
- [ ] 액세스 키는 코드·저장소·채팅에 없고 내 컴퓨터 설정에만 있다
- [ ] 클로드가 허용된 명령으로만 파일을 올렸고, 삭제는 거부됐다
- [ ] Lightsail 서버를 만들고 바로 지웠고 청구 화면에서 확인했다
- [ ] 리전을 한 곳으로 정했다
- [ ] 쓰지 않는 리소스가 없는지 정기 점검 날짜를 달력에 적었다
