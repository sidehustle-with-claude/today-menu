## 40장 텔레그램으로 알림받고 지시하기
요금제: Pro로 충분
선행 장: 8
사람 몫: 봇 만들기(BotFather)·내 chat id 확인
요약
- 컴퓨터 앞에 없어도 작업 끝, 오류, 사람이 해야 할 단계를 폰으로 받습니다.
- 알림만 보내는 단방향과, 폰에서 지시하고 답을 받는 양방향을 구분해 둘 다 만듭니다.
- 내 계정이 아닌 사람의 메시지는 무시하도록 허용 목록을 거는 법을 익힙니다.
체크리스트
- [ ] BotFather에서 봇을 만들고 토큰을 `.env`에 넣었다
- [ ] `.env`가 `.gitignore`에 있고 토큰이 깃에 없다
- [ ] `getUpdates`로 chat id를 찾아 `.env`에 넣었다
- [ ] `notify.sh`로 폰에 알림이 온다
- [ ] Stop 훅과 Notification(permission_prompt) 훅을 걸었고 종료 코드가 늘 0이다
- [ ] 알림 글이 제목 한 줄과 `- ` 줄로 간결하다
- [ ] channels용 텔레그램 플러그인을 설치하고 `--channels`로 켰다
- [ ] 짝짓기 후 `policy allowlist`로 나만 보낼 수 있게 잠갔다
- [ ] 폰에서 보낸 지시에 대한 답이 텔레그램으로 온다
