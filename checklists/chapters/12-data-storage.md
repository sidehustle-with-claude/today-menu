## 12장 데이터는 어디에 두나: 로컬 DB와 서버 DB
요금제: Pro로 충분
선행 장: 3, 11
사람 몫: 서비스 가입·이메일 인증·결제 수단
요약
- 파일, 로컬 저장, 서버 DB가 어떻게 다른지 설명할 수 있습니다
- 오늘 뭐 먹지의 즐겨찾기를 브라우저에 저장하고, 새로 고침해도 남는지 확인합니다
- 개발용 DB와 운영용 DB를 나누고, 클로드에게 위험한 권한을 주지 않는 법을 압니다
체크리스트
- [ ] 공공데이터 CSV를 JSON 파일로 바꾸고 건수를 확인했다
- [ ] 즐겨찾기를 localStorage에 저장했고 새로 고침 후에도 남는다
- [ ] 시크릿 창에서 비어 있음을 확인했다
- [ ] 서버 DB로 옮기는 계획을 클로드에게 먼저 세우게 했다
- [ ] .env 파일을 개발용과 운영용으로 나누고 .gitignore에 넣었다
- [ ] 클로드에게 운영 DB 쓰기 권한을 주지 않았다
- [ ] 표 변경은 마이그레이션 파일로 남기도록 CLAUDE.md에 적었다
- [ ] 사용할 서비스의 무료 한도를 공식 페이지에서 다시 확인했다
