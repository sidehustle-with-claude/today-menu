## 38장 광고 붙이기
요금제: Pro로 충분
선행 장: 25, 30, 33, 34, 37
사람 몫: 승인 신청·약관·세금 정보·지급 설정
요약
- 웹은 애드센스, 앱은 AdMob이라는 차이와 광고가 돈이 되는 구조를 이해합니다.
- 내 서비스에 광고를 넣을지 말지 판단하는 기준을 갖습니다.
- 웹에 애드센스 코드와 ads.txt를 붙이고, 앱에 AdMob 테스트 광고를 띄웁니다.
체크리스트
- [ ] 광고를 넣을지 말지 사용성·방문자 수·결제 비교로 판단해 적었다
- [ ] 애드센스 가입과 사이트 추가를 사람이 마쳤다
- [ ] 사이트에 광고 코드를 넣었고 게시자 ID는 코드가 아닌 환경변수에 있다
- [ ] `ads.txt`가 `내도메인/ads.txt`에서 열린다
- [ ] 앱에서 테스트 광고가 뜬다
- [ ] 개발 모드에서 실제 광고 단위가 쓰이지 않는 것을 코드로 확인했다
- [ ] 개인정보처리방침과 스토어 데이터 양식에 광고 SDK를 적었다
- [ ] 호스팅 플랜이 광고 사이트를 허용하는지 확인했다
