## 41장 컴퓨터는 켜 두기만 하고 폰으로 다 하기
요금제: Max 권장
선행 장: 2, 40
사람 몫: 문자 인증번호, 결제 인증, 자동 로그인 결정
요약
- 맥이 잠들거나 정전으로 꺼져도 다시 살아나, 폰으로 세션을 여는 환경을 만듭니다.
- Remote Control로 폰에서 내 컴퓨터의 클로드 세션을 열고 일을 시킵니다.
- 사람이 꼭 해야 하는 단계(인증번호, 결제 확인)만 폰으로 처리하고 나머지는 클로드가 하게 나눕니다.
체크리스트
- [ ] 상시 켜 둘 맥이 있고 전원을 꽂아 뒀다
- [ ] 잠자기를 껐거나 `caffeinate`로 막았다
- [ ] `sudo pmset -a autorestart 1`을 사람이 직접 실행했다
- [ ] 자동 로그인은 집 안 기기에서만 켰다
- [ ] `revive-sessions.sh`와 launchd 설정을 만들고 내용을 확인한 뒤 설치했다
- [ ] 각 프로젝트 폴더를 터미널에서 한 번 열어 믿음을 저장했다
- [ ] 폰 Claude 앱에서 `today-menu` 세션이 초록 점으로 보인다
- [ ] 폰에서 "오늘 접속자 수 알려 줘"를 시켜 답을 받았다
- [ ] 허용 목록, 폰 잠금, 2단계 인증을 확인했다
