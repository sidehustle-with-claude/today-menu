## 4장 CLAUDE.md로 내 규칙 가르치기
요금제: Pro로 충분
선행 장: 3
사람 몫: (없음)
요약
- 클로드가 대화를 시작할 때마다 읽는 규칙 메모, CLAUDE.md를 직접 만듭니다.
- 짧고 구체적이고 확인할 수 있는 규칙 문장을 쓰는 법을 익힙니다.
- 규칙을 써 놨는데 안 지킬 때 원인을 찾는 순서를 알게 됩니다.
체크리스트
- [ ] `today-menu` 루트에 `CLAUDE.md`가 있다
- [ ] 규칙에 한국어 답변, 커밋 메시지 형식, `.env` 금지가 들어 있다
- [ ] `/clear` 뒤 같은 질문으로 규칙 전후를 비교해 메모했다
- [ ] 모든 규칙이 한 줄이고 구체적이다 (모호한 형용사가 없다)
- [ ] CLAUDE.md가 200줄 안쪽이다
- [ ] 키, 비밀번호, 개인정보가 파일에 없다
- [ ] `/context`의 "Memory files"에서 내 CLAUDE.md가 보인다
- [ ] 개인 습관은 `~/.claude/CLAUDE.md`로, 프로젝트 규칙은 루트 파일로 나눴다
