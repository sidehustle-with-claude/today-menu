## 19장 Max 구독 월 API 크레딧과 무료 API(Gemini Flash 등) 활용
요금제: Pro로 충분
선행 장: 16, 17
사람 몫: 크레딧 연결·약관 동의·결제, 키 발급 로그인
요약
- 내 요금제로 API 크레딧을 받을 수 있는지, 못 받으면 얼마를 충전할지 정합니다.
- 같은 입력 10개를 무료 API와 클로드 Haiku로 돌려, 품질·속도·비용을 비교표로 만듭니다.
- 작업별 배분표를 만들고, 한도를 넘어도 서비스가 멈추지 않는 대체 경로를 둡니다.
체크리스트
- [ ] 내 요금제에 API 크레딧이 있는지 확인했다
- [ ] 크레딧 연결과 약관 동의를 직접 했다 (사람 몫, 대상 요금제만)
- [ ] Pro라면 소액 충전과 월 지출 상한을 걸었다
- [ ] 프로젝트별 워크스페이스에 지출 한도를 걸었다
- [ ] 무료 API 키를 `.env`에 넣었고 코드에는 없다
- [ ] 입력 10개와 정답을 직접 확인해 만들었다
- [ ] 비교표(일치, 깨짐, 시간, 비용)를 직접 채웠다
- [ ] 작업별 배분표를 만들었다
- [ ] 호출부가 `llm.ts` 한 곳이고 모델 이름은 `llm.config.json`에 있다
- [ ] 한도 초과 시 코드 기반 추천으로 내려가는 것을 확인했다
