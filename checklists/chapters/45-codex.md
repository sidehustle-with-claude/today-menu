## 45장 Codex 같이 쓰기
요금제: Pro로 충분
선행 장: 3, 4, 43
사람 몫: Codex 로그인·구독 결제
요약
- 클로드와 Codex가 어떻게 다르고 어떤 일을 나눠 맡기면 좋은지 알게 됩니다.
- 클로드가 쓴 변경분을 Codex에게 리뷰시키고, 결과를 클로드에게 돌려주는 흐름을 한 번 해 봅니다.
- Codex로 이미지를 만들어 받고, 두 도구가 같은 파일을 동시에 고치지 않는 규칙을 세웁니다.
체크리스트
- [ ] Codex CLI를 공식 페이지의 방법으로 설치하고 로그인했다
- [ ] 커밋 전 변경을 `/review`로 리뷰시켰다
- [ ] 리뷰 지적을 클로드에게 판단시킨 뒤 맞는 것만 고쳤다
- [ ] 이미지 프롬프트를 영어로 쓰고 아이콘을 하나 만들었다
- [ ] 두 도구가 같은 파일을 동시에 고치지 않는 규칙(브랜치 또는 폴더)을 정했다
- [ ] 공통 규칙을 AGENTS.md 한 곳에 두고 CLAUDE.md에서 가져오게 했다
- [ ] 두 구독의 월 비용을 합쳐 확인했다
