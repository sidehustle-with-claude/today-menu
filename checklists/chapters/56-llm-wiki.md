## 56장 LLM 위키: 클로드가 직접 쓰고 고치는 내 지식 창고
요금제: Max 권장
선행 장: 4, 7, 8
사람 몫: 저장소 공개·비공개 결정 (처음엔 비공개), 개인정보·비밀값은 적지 않는다
요약
- 검색해서 붙이는 방식(RAG, 질문마다 관련 문서 조각을 찾아 AI에게 붙여 주는 방식)과, 클로드가 직접 정리하는 마크다운 창고(LLM 위키)의 차이를 설명합니다.
- 폴더, 프론트매터, 목차 파일, 시작 훅으로 이루어진 작은 위키를 직접 만듭니다.
- 사실(지식)과 우리가 정한 것(결정)을 나누고, 낡은 문서를 폐기하는 법을 익힙니다.
체크리스트
- [ ] `knowledge/`와 `decisions/`를 나눈 저장소를 만들었다
- [ ] 문서 하나를 프론트매터와 `- 줄`로 썼다
- [ ] `CATALOG.md`에 한 줄을 더했다
- [ ] SessionStart 훅으로 결정 제목을 넣었다
- [ ] 세션당 한 번 기록을 되묻는 Stop 훅을 걸었다
- [ ] 폐기 문서에 `status: retired`와 `superseded_by`를 적었다
- [ ] 창고에 개인정보와 실제 키가 없는지 검사했다
