## 8장 훅으로 실수 미리 막기
요금제: Pro로 충분
선행 장: 3, 4
사람 몫: jq 설치·settings.json 편집, 컴퓨터 비밀번호 입력
요약
- 훅이 무엇이고 CLAUDE.md의 규칙과 어떻게 다른지 설명할 수 있게 됩니다.
- `.env` 접근 차단, 수정 뒤 자동 포맷, 커밋 전 비밀 검사 훅을 직접 만듭니다.
- 훅이 안 걸리거나 계속 막을 때 푸는 순서를 익힙니다.
체크리스트
- [ ] `jq`가 설치되어 있다
- [ ] `.claude/hooks/protect-files.sh`가 있고 `chmod +x`를 했다
- [ ] `.claude/settings.json`에 `PreToolUse` 훅이 등록되어 있다
- [ ] `/hooks`에서 내 훅이 보인다
- [ ] `.env`를 읽으라고 시켰더니 차단되는 것을 확인했다
- [ ] 파일 수정 뒤 `PostToolUse` 포맷 훅이 동작하는 것을 확인했다
- [ ] 가짜 키를 넣은 파일의 커밋이 막히는 것을 확인하고 정리했다
- [ ] `rm -rf`와 강제 푸시를 막거나 묻는 훅을 만들었다
- [ ] 차단은 `exit 2`로 하고 `exit 1`을 쓰지 않았다
- [ ] 훅이 막을 때 우회하지 않고 설정 파일을 직접 고치는 방법을 알고 있다
