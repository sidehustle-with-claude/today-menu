## 29장 GitHub 블로그
요금제: Pro로 충분
선행 장: 3, 25
사람 몫: 저장소 공개 결정·2단계 인증
요약
- GitHub Pages로 무료 정적 웹사이트를 공개 주소에 띄웁니다
- 개발 중 쌓인 기록을 글감으로 바꾸고, 공개 전에 위험한 내용을 걸러 냅니다
- 제목·첫 문단·소제목·이미지 설명 같은 글 구조의 기본기를 익힙니다
체크리스트
- [ ] 저장소 `<계정>.github.io`를 공개로 만들고 Pages를 'Deploy from a branch'로 켰다
- [ ] 첫 글이 공개 주소에서 열린다
- [ ] 글 파일 이름에 한글·공백이 없다
- [ ] 공개 전 점검(키, 개인정보, 회사 이야기, 남의 저작물)을 클로드로 한 번 돌리고 사람이 전체를 읽었다
- [ ] 글마다 제목 1개, 첫 문단, 소제목, 이미지 대체 텍스트가 있다
- [ ] 푸시 후 10분 안에 반영되는지 확인했다
- [ ] 블로그 저장소에 `.env`·메모·초안 파일이 없다
