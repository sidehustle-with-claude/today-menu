## 42장 이메일 연결하기
요금제: Pro로 충분
선행 장: 7, 30, 40
사람 몫: 구글 로그인·2단계 인증, 발송 도메인 DNS 승인
요약
- 메일에서 무엇을 클로드에게 맡기고 무엇을 사람이 할지 선을 긋습니다.
- 공식 커넥터, MCP 서버, 메일 발송 API 세 가지 연결 방법을 비교해 고릅니다.
- 문의 메일 요약, 답장 초안 저장, 서비스가 보내는 환영 메일까지 만들어 봅니다.
- 메일 본문에 숨은 지시를 따르지 않게 하는 안전 규칙을 갖춥니다.
체크리스트
- [ ] 메일에서 맡길 일과 사람이 할 일을 표로 나눠 적었다
- [ ] claude.ai에서 Gmail 커넥터를 연결했고 `/mcp`에서 보인다
- [ ] "오늘뭐먹지 문의" 라벨 메일만 읽어 하루 한 번 요약한다
- [ ] 요약에 개인정보를 옮기지 않는 규칙을 `CLAUDE.md`에 넣었다
- [ ] 답장은 초안으로만 저장하고 사람이 직접 보낸다
- [ ] 보내기 도구를 거부하는 권한 규칙을 걸었다
- [ ] 가짜 메일의 숨은 지시를 따르지 않고 경고하는 것을 확인했다
- [ ] 발송 서비스 키가 `.env`에만 있고 깃에 없다
- [ ] 발송 도메인의 SPF·DKIM 인증 상태를 확인했다
