## 23장 TestFlight가 뭔지와 쓰는 법
요금제: Pro로 충분
선행 장: 22
사람 몫: Apple 가입·결제·2단계 인증·약관 동의
요약
- TestFlight가 무엇이고 왜 앱스토어 출시 전에 꼭 거치는지 설명할 수 있습니다.
- Expo의 EAS Build로 iOS 빌드를 만들어 TestFlight에 올릴 수 있습니다.
- 내 iPhone에 TestFlight 앱으로 "오늘 뭐 먹지"를 설치해 볼 수 있습니다.
체크리스트
- [ ] Apple Developer Program에 직접 가입했다
- [ ] app.json에 번들 ID와 버전이 있고 App Store Connect의 값과 같다
- [ ] eas-cli를 설치하고 eas login을 했다
- [ ] eas build --platform ios로 빌드를 만들었다
- [ ] App Store Connect에 앱 레코드를 만들었다
- [ ] 빌드를 올리고 수출 규정 질문에 답했다
- [ ] 내부 테스터로 나를 넣고 TestFlight 앱으로 설치했다
- [ ] 빌드 만료일(90일)과 EAS 무료 빌드 횟수를 달력에 적었다
