## 33장 앱·게임도 웹페이지가 있어야 검색에 걸린다
요금제: Pro로 충분
선행 장: 25, 31, 32
사람 몫: 연락처·사업자 정보 입력, 스토어 링크
요약
- 스토어 안의 앱이 왜 검색에 잘 안 걸리는지 알고, 내 앱 이름으로 직접 확인합니다
- 소개 페이지, 업데이트 글, 사용법 글을 만들어 검색과 스토어를 잇습니다
- 스토어 심사에 필요한 `/privacy`와 `/support` 주소를 로그인 없이 열리게 둡니다
체크리스트
- [ ] 앱 이름과 문제 문장으로 검색해 현재 노출 상태를 기록했다
- [ ] 소개 페이지에 h1 하나, 기능 h2, 스크린샷 alt, 출처 표기, 푸터 링크가 있다
- [ ] `curl`로 받은 HTML에 본문이 있다
- [ ] 업데이트 글 한 편과 사용법 글 한 편을 소개 페이지에서 링크했다
- [ ] `/privacy`와 `/support`가 로그아웃 상태에서 200으로 열린다
- [ ] 예시 연락처가 실제 값으로 바뀌었다
- [ ] 구조화 데이터에 없는 평점·리뷰를 넣지 않았다
- [ ] 이미지 파일 이름과 alt가 내용을 설명한다
- [ ] 심사 제출용 처리방침 주소를 정했다(39장에서 사용)
