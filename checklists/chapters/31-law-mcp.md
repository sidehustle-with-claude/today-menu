## 31장 법령 MCP로 약관·개인정보처리방침 확인하기
요금제: Pro로 충분
선행 장: 7, 27
사람 몫: 내용 확정·게시 책임, 사업자 정보 입력
요약
- 앱과 웹을 내놓을 때 왜 개인정보처리방침과 이용약관이 필요한지 알게 됩니다
- 법령 MCP로 클로드가 법령 원문을 찾아 읽게 하고, 국가법령정보센터 원문과 대조합니다
- 예제 서비스가 모으는 정보를 표로 정리하고 처리방침·약관 초안을 만들어 빠진 항목을 점검합니다
체크리스트
- [ ] 법령 MCP 설치 전 저장소 주소, 라이선스, 마지막 업데이트를 확인했다
- [ ] `/mcp`에서 법령 도구가 연결됨으로 보인다
- [ ] 클로드에게 "원문 링크 없이 인용하지 말라"는 규칙을 줬다
- [ ] 서비스가 모으는 정보 표를 코드 기준으로 만들고 사람이 사실 확인했다
- [ ] 처리방침 초안을 만들고 빠진 항목을 법령 원문으로 대조했다
- [ ] 클로드가 인용한 조 번호를 국가법령정보센터에서 직접 열어 봤다
- [ ] 이용약관 초안과 외부 서비스 대응표를 만들었다
- [ ] 사업자 정보는 직접 입력했고 예시 값이 남아 있지 않다
- [ ] 이 문서들이 법률 자문이 아님을 알고 있다
