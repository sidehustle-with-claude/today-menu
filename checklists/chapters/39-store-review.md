## 39장 앱스토어·플레이 심사 통과하기
요금제: Pro로 충분
선행 장: 23, 24, 31, 33, 37, 38
사람 몫: 제출 버튼·연령 등급·수출 규정·심사 연락
요약
- 스토어 심사가 무엇을 보는지, 왜 거절되는지 유형별로 압니다.
- 심사 지침 원문을 클로드에게 읽혀 내 앱 전용 제출 전 점검표를 만듭니다.
- 메타데이터·개인정보 양식·심사 메모를 채우고, 거절 메시지를 받았을 때 고쳐서 다시 내는 순서를 익힙니다.
체크리스트
- [ ] 클로드가 심사 지침 원문을 읽고 만든 제출 전 점검표가 있다
- [ ] 앱 코드에서 계정 삭제, 권한 문구, 광고 동의 흐름을 확인했다
- [ ] 개인정보처리방침과 지원 주소가 앱 안과 스토어 양식에 모두 들어갔다
- [ ] 스토어 설명과 스크린샷이 실제 앱 기능과 일치한다
- [ ] 데이터 보안 양식과 방침, 코드의 수집 항목이 서로 같다
- [ ] 심사 메모와 데모 계정을 준비했다(실제 비밀번호는 사람이 입력)
- [ ] 가짜 거절 메시지로 회신 문안 쓰기를 연습했다
- [ ] 구글 개인 계정이면 12명·14일 닫힌 테스트 일정을 계산했다
