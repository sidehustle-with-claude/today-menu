## 46장 Whisper로 음성 받아쓰기와 자막 만들기
요금제: Pro로 충분
선행 장: 2
사람 몫: 녹음 허락 받기
요약
- Whisper를 내 맥에 설치해 1~2분짜리 녹음을 글로 받아 적습니다.
- 결과를 SRT 자막 파일로 뽑아 47장에서 영상에 얹을 준비를 합니다.
- 모델 크기마다 속도와 정확도가 어떻게 다른지 같은 파일로 재서 표를 만듭니다.
체크리스트
- [ ] `brew install ffmpeg`와 Whisper 설치를 마쳤고 `whisper --help`가 나온다
- [ ] 1~2분 녹음을 `--language Korean`으로 받아 적었다
- [ ] SRT 파일을 만들었다
- [ ] 같은 파일로 모델 크기별 속도와 정확도를 표로 만들었다
- [ ] 클로드로 자막 문장을 고치되 시간표가 같은지 검사했다
- [ ] 남의 목소리가 든 녹음은 허락을 받았다
- [ ] 서버 API로 보내기 전에 보낼지 한 번 판단했다
