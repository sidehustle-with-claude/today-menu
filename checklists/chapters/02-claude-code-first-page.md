## 2장 클로드 코드 설치하고 내 컴퓨터에서 첫 웹페이지 만들기
요금제: Pro로 충분
선행 장: 1
사람 몫: 로그인(브라우저 인증), 요금제 결제
요약
- 클로드 코드를 내 컴퓨터에 설치하고 로그인합니다.
- 빈 폴더에서 "오늘 뭐 먹지" 첫 화면을 index.html 한 장으로 만들어 브라우저로 엽니다.
- 허락 창을 읽고, 허락할 것과 거절할 것을 가려내는 기준을 갖습니다.
체크리스트
- [ ] 터미널을 열고 `pwd`, `ls`, `cd`를 한 번씩 쳐 봤다
- [ ] 운영체제에 맞는 설치 명령으로 클로드 코드를 설치했다
- [ ] `claude --version` 으로 버전 숫자가 나오는 것을 확인했다
- [ ] `claude` 를 실행하고 브라우저로 로그인했다 (사람 몫)
- [ ] 빈 폴더 `today-menu`를 만들었다
- [ ] 클로드에게 index.html 첫 화면을 만들게 했다
- [ ] index.html을 브라우저로 열어 동네 입력창, 버튼 4개, 카드 3개를 확인했다
- [ ] 허락 창에서 'Yes'를 골라 파일 생성을 허락했다
- [ ] `Esc` 로 멈추기, `/clear`, `/exit` 를 한 번씩 써 봤다
- [ ] `/permissions` 에서 지금 허락된 규칙을 확인했다
