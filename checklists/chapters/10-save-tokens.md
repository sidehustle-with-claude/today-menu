## 10장 토큰 아끼기: Pro 요금제로 1~8부를 끝내는 법
요금제: Pro로 충분
선행 장: 2, 9
사람 몫: 추가 사용량 켜기·결제 설정
요약
- 토큰과 컨텍스트가 무엇인지, 사용량이 왜 빨리 닫히는지 설명할 수 있게 됩니다.
- 5시간 한도와 주간 한도를 확인하고, 닫혔을 때 대처하는 법을 익힙니다.
- 사용량을 아끼는 다섯 가지 습관을 "오늘 뭐 먹지" 작업에 적용해 전후를 비교합니다.
체크리스트
- [ ] `/usage`로 5시간 한도와 주간 한도의 현재 %를 확인했다
- [ ] `/context`로 컨텍스트를 차지하는 항목을 확인했다
- [ ] 기본 모델을 Sonnet으로 바꿨다
- [ ] 일의 단위가 끝나면 `/rename`과 `/clear`로 새 대화를 시작하는 습관을 만들었다
- [ ] CLAUDE.md가 200줄 안쪽이다
- [ ] 쓰지 않는 MCP 서버와 스킬을 끄거나 지웠다
- [ ] 잔일용 서브에이전트에 `model: haiku`를 지정하는 방법을 확인했다
- [ ] 반복 작업 하나를 스크립트로 바꿀 후보로 적어 두었다
- [ ] 장별 사용량 측정표를 한 장 이상 채웠다
- [ ] 같은 작업을 전후로 나눠 측정해 소진 %를 비교했다
- [ ] 키와 개인정보를 다른 서비스의 무료 등급에 넣지 않았다
- [ ] 한도가 닫혔을 때 할 일 순서를 알고 있다
