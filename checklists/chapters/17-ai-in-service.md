## 17장 서비스에 AI 넣기: API와 구독형은 무엇이 다른가
요금제: Pro로 충분
선행 장: 16
사람 몫: 콘솔 가입·결제 수단, 월 상한 금액
요약
- 구독형(클로드 앱·클로드 코드)과 API가 어떻게 다른지, 왜 서비스에는 API만 쓰는지 설명할 수 있습니다.
- API 키를 안전하게 보관하고, "한 줄 취향 입력"을 필터 JSON으로 바꾸는 첫 호출을 만듭니다.
- 모델별 단가로 월 비용을 계산하고, 서비스마다 월 상한을 거는 방법을 익힙니다.
체크리스트
- [ ] 콘솔 가입과 결제 설정은 사람이 직접 마쳤다
- [ ] 서비스 전용 워크스페이스를 만들고 그 안에서 키를 발급했다
- [ ] 키는 `.env`에만 있고 `.gitignore`에 `.env`가 들어 있다
- [ ] 브라우저로 내려가는 코드에 키가 없다
- [ ] `src/parse-taste.ts`가 목업(`MOCK_LLM=1`)과 실제 호출 둘 다 동작한다
- [ ] 응답을 `zod`로 검사하고 입력은 100자로 제한한다
- [ ] 내 `usage` 숫자로 월 비용을 계산해서 적어 두었다
- [ ] 워크스페이스 또는 조직의 월 상한을 설정했다
- [ ] 모델 이름은 환경변수 `TASTE_MODEL`로 뺐다
