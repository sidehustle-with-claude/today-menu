## 34장 GA 붙이기
요금제: Pro로 충분
선행 장: 25, 31
사람 몫: 구글 로그인·약관 동의
요약
- GA4가 무엇을 세고 무엇을 못 세는지 알고, 계정·속성·데이터 스트림 구조를 이해합니다
- 측정 ID로 웹에 태그를 붙이고, 실시간 보고서에서 내 방문이 잡히는지 확인합니다
- 즐겨찾기 클릭 이벤트를 직접 만들고 주요 이벤트로 표시합니다
체크리스트
- [ ] GA4 계정·속성·웹 데이터 스트림을 만들었다
- [ ] 측정 ID를 환경변수로 넣고 코드에 직접 쓰지 않았다
- [ ] 개발 환경에서는 태그가 동작하지 않는다
- [ ] 실시간 보고서에 내 방문이 잡힌다
- [ ] `favorite_add` 이벤트를 만들었고 개인정보를 보내지 않는다
- [ ] 주요 이벤트 표시를 한 개 이상 했다
- [ ] 처리방침(31장)에 GA 사용을 적었다
- [ ] 클로드에게는 요약 숫자만 준다
- [ ] 이벤트 보존 기간을 확인했다
