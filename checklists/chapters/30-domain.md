## 30장 도메인 사서 연결하기
요금제: Pro로 충분
선행 장: 25, 29
사람 몫: 결제·소유자 정보 입력·본인 확인·약관 동의
요약
- 도메인과 DNS가 무엇인지 비유로 이해하고, 레코드 종류를 구분합니다
- 도메인을 사는 순서와 개인정보 보호 옵션을 확인합니다
- Vercel 배포와 GitHub Pages 블로그에 내 도메인을 연결하고, `dig`로 맞게 들어갔는지 확인합니다
체크리스트
- [ ] 도메인 갱신가와 개인정보 보호 옵션을 확인하고 구매했다
- [ ] 자동 갱신을 켰고 카드 만료일을 달력에 적었다
- [ ] 소유자 정보에 실제 정보는 내가 직접 입력했다(클로드 대화에 붙이지 않음)
- [ ] Vercel 프로젝트에 apex와 www를 추가했다
- [ ] GitHub Pages 저장소 설정에 서브도메인을 먼저 넣은 뒤 CNAME 레코드를 만들었다
- [ ] 와일드카드 레코드를 만들지 않았다
- [ ] `dig` 결과가 기대한 값과 같다
- [ ] 브라우저에서 HTTPS로 열린다
