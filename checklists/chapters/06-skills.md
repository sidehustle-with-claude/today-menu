## 6장 스킬 활용하기
요금제: Pro로 충분
선행 장: 4, 5
사람 몫: (없음)
요약
- 스킬이 무엇이고 CLAUDE.md와 어떻게 다른지 설명할 수 있게 됩니다.
- 공식 문서 스킬로 "오늘 뭐 먹지" 소개서를 문서 파일로 만듭니다.
- 작은 스킬 하나를 직접 만들고, 안 불릴 때 고치는 법을 익힙니다.
체크리스트
- [ ] 스킬과 CLAUDE.md의 차이를 한 문장으로 말할 수 있다
- [ ] 공식 문서 스킬을 설치하고 소개서 파일(`today-menu-intro.pptx` 등)을 만들었다
- [ ] `.claude/skills/menu-summary/SKILL.md`를 만들었다
- [ ] `/menu-summary`로 직접 불러 양식이 지켜지는지 확인했다
- [ ] 이름 없이 요청해도 스킬이 불리는지 확인했다
- [ ] description에 언제 쓰는지와 내가 쓸 표현이 들어 있다
- [ ] 설치한 남의 스킬의 `SKILL.md`와 `scripts/`를 읽어 외부 전송, 삭제, 키 읽기가 없음을 확인했다
- [ ] 부작용이 있는 스킬에 `disable-model-invocation: true`를 넣었다
