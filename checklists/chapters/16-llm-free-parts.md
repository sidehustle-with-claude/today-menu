## 16장 LLM 없이도 굴러가는 부분 만들기
요금제: Pro로 충분
선행 장: 15
사람 몫: (없음)
요약
- "오늘 뭐 먹지"의 추천 로직을 LLM 없이, 같은 입력이면 늘 같은 결과로 만듭니다.
- 클로드가 한 번 해 준 작업을 스크립트로 굳히고, 한 번 구한 답은 저장해서 다시 쓰는 법을 익힙니다.
- 추천 함수에 테스트 5개를 붙여서 고쳐도 안 깨지는지 스스로 확인합니다.
체크리스트
- [ ] `src/recommend.ts`가 있고, 동점 규칙(거리, id)이 들어 있다
- [ ] `recommend`는 랜덤·현재 시각·네트워크를 쓰지 않는다
- [ ] 같은 입력 100번 실행 결과가 모두 같다 (`scripts/repeat-check.ts`)
- [ ] 반복해서 시킨 작업 하나를 스크립트로 만들고 방금 결과와 같은지 비교했다
- [ ] `src/cache.ts`가 있고, 키에 입력·프롬프트 버전·모델이 들어간다
- [ ] `.cache`가 `.gitignore`에 들어 있다
- [ ] 테스트 5쌍이 있고 `npx vitest run`이 통과한다
