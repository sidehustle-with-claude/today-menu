## 55장 한 번 한 일을 스킬로 만들기
요금제: Max 권장
선행 장: 6, 54
사람 몫: 메시지 실제 발송 허용 (처음엔 내 개인 채팅방만)
요약
- "같은 설명을 두 번 했다면 스킬로 만든다"는 기준으로, 스킬로 만들 일을 골라냅니다.
- 설명(description), 본문, 스크립트가 들어간 스킬 폴더를 직접 만들고 호출합니다.
- 비밀값, 큰 스킬 쪼개기, 56장 LLM 위키와의 구분까지 정리합니다.
체크리스트
- [ ] 두 번 이상 설명한 일 중 스킬로 만들 후보를 골랐다
- [ ] `~/.claude/skills/<이름>/SKILL.md`를 만들었다
- [ ] 설명에 "언제 쓰는지"를 넣었다
- [ ] 고정된 부분을 `scripts/`로 분리했다
- [ ] 비밀값이 스킬 폴더 안에 없다
- [ ] `/이름`으로 직접 불러 보고, 말로도 불리는지 확인했다
- [ ] SKILL.md가 500줄 이하다
