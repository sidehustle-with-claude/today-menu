## 27장 Supabase
요금제: Pro로 충분
선행 장: 12, 25, 26
사람 몫: 가입·이메일 확인·결제·DB 비밀번호 보관
요약
- Supabase가 DB, 로그인, 파일 저장을 한 상자로 묶어 준다는 것을 설명할 수 있습니다.
- 즐겨찾기와 후기 표를 만들고, 이메일 로그인을 붙이고, "내 즐겨찾기만 보이게" 만들 수 있습니다.
- 공개 키와 비밀 키의 차이를 알고, 비밀 키를 절대 앱·웹 코드에 넣지 않습니다.
체크리스트
- [ ] Supabase 프로젝트를 만들고 DB 비밀번호를 비밀번호 관리자에 보관했다
- [ ] 공개 키와 비밀 키의 차이를 구분하고, 비밀 키는 코드·저장소·채팅에 없다
- [ ] favorites, reviews 표를 SQL 파일로 만들고 실행 전에 직접 읽어 봤다
- [ ] 이메일 로그인을 붙였고 확인 메일은 직접 열었다
- [ ] RLS를 켜기 전과 후를 계정 두 개로 비교했다
- [ ] 모든 표에 RLS가 켜져 있다
- [ ] CLAUDE.md에 RLS와 비밀 키 규칙을 넣었다
- [ ] MCP를 연결했다면 읽기 전용과 프로젝트 한정을 적용했다
- [ ] Vercel 환경변수에 공개 키와 URL을 넣었다
