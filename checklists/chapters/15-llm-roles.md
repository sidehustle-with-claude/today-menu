## 15장 LLM이 잘하는 것과 못하는 것 나누기
요금제: Pro로 충분
선행 장: 11, 12
사람 몫: 받을 개인정보와 이용자 안내 범위 결정
요약
- LLM이 잘하는 일과 못하는 일을 구분하고, 환각이 왜 생기는지 설명할 수 있습니다
- 정해진 규칙은 코드, 말을 이해하는 일은 LLM, 섞이면 코드가 사실을 주고 LLM이 말만 만드는 기준을 압니다
- 오늘 뭐 먹지의 기능 5가지를 직접 분류하고, 같은 질문을 여러 번 해서 결과가 다름을 확인합니다
체크리스트
- [ ] 오늘 뭐 먹지 기능 5가지를 코드/LLM/섞음으로 분류한 표를 채웠다
- [ ] LLM을 쓸 기능이 1~2개로 줄었다
- [ ] 같은 질문을 3번 보내 답이 달라지는 것을 확인했다
- [ ] 없는 가게로 환각이 생기는지 확인했다
- [ ] 평가용 데이터 10개를 eval/cases.json으로 만들었다
- [ ] 개인정보를 LLM에 넣지 않는 규칙을 CLAUDE.md에 적었다
- [ ] 가게 이름·시간·가격은 데이터에서만 가져온다는 규칙을 CLAUDE.md에 적었다
