## 20장 다국어 작업: 화면·스토어 문구·검색을 여러 언어로
요금제: Pro로 충분
선행 장: 16, 17
사람 몫: 영어 번역 검수, 약관·방침 검수
요약
- 어디까지 번역할지 범위를 정합니다. 화면, 스토어 문구, 검색 노출 세 가지로 나눕니다.
- 번역 파일(`ko.json`, `en.json`)로 문구를 빼고, 언어 선택 버튼으로 한/영을 전환합니다.
- 용어집과 누락 검사 스크립트로 번역 품질과 비용을 관리합니다.
체크리스트
- [ ] 번역 범위(화면, 스토어, 검색)를 정했다
- [ ] 화면 문구를 `ko.json`, `en.json`으로 뺐다
- [ ] 언어 선택 버튼으로 한/영이 바뀌고, 선택이 저장된다
- [ ] 용어집을 만들고 번역에 같이 썼다
- [ ] 숫자·날짜 형식을 `Intl`로 맞췄다
- [ ] 영어 화면에서 글자가 넘치는 곳이 없다
- [ ] 스토어 문구 글자 수를 제한과 비교했다
- [ ] 영어 번역을 지인에게 보여 어색한 곳을 고쳤다 (사람 몫)
- [ ] 약관과 개인정보 처리방침은 사람이 검수했다 (사람 몫)
- [ ] 누락 검사 스크립트를 만들고 테스트에 연결했다
