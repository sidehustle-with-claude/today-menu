## 50장 세션 여러 개 띄우고 서로 소통시키기
요금제: Max 권장
선행 장: 3, 49
사람 몫: 비밀값은 세션 메시지로 주고받지 않기
요약
- 터미널 탭마다 세션 하나를 띄우고, 워크트리로 같은 저장소를 나눠 쓰는 법을 익힙니다.
- 세션끼리 메시지를 주고받게 하고, 한 세션이 끝나면 알림을 받습니다.
- 서브에이전트, 세션 간 메시지, 에이전트 팀 중 무엇을 고를지 표로 정하고, 안전장치와 토큰 비용을 이해합니다.
체크리스트
- [ ] `claude --version`으로 v2.1.224 이상을 확인했다
- [ ] 워크트리 세션 둘을 서로 다른 이름으로 띄웠다
- [ ] `/rename` 또는 `--name`으로 세션 이름을 붙였다
- [ ] `/list-agents`로 상대 세션이 보이는지 확인했다
- [ ] 한 세션에서 다른 세션으로 메시지를 보냈다
- [ ] 끝나면 알림을 받도록 신청해 봤다
- [ ] `crossSessionInbound` 값을 확인하고 의미를 말할 수 있다
- [ ] 서브에이전트, 세션 간 메시지, 에이전트 팀 중 고르는 기준을 표로 정리했다
- [ ] 세션 수가 늘어난 만큼 `/usage`를 확인했다
