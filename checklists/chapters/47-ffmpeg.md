## 47장 ffmpeg로 영상과 소리를 명령 한 줄로 다루기
요금제: Pro로 충분
선행 장: 44, 46
사람 몫: 완성된 영상 보고 올리기, 음악·사진 저작권 확인
요약
- 영상 파일의 구성을 이해하고, 자르기·소리 뽑기·해상도 줄이기를 명령 한 줄로 합니다.
- 46장의 SRT 자막을 영상에 입히고, 사진과 음악으로 소개 영상을 만들어 세로판과 가로판을 뽑습니다.
- 원본을 지키며 명령을 시키는 요령과, 배경음악이 목소리를 덮지 않게 음량을 맞추는 법을 익힙니다.
체크리스트
- [ ] `ffmpeg -version`이 나온다
- [ ] 원본은 그대로 두고 `output/` 폴더에 새 파일로 저장한다
- [ ] 명령에 `-n`을 붙였다
- [ ] 자르기, 소리 뽑기, 해상도 줄이기를 한 번씩 해 봤다
- [ ] SRT 자막을 입혔고 한글이 깨지지 않았다
- [ ] 가로판과 세로판을 둘 다 뽑았다
- [ ] 배경음악이 목소리를 덮지 않는지 폰 스피커로 들어 봤다
- [ ] 폰에서 재생되는지 확인했다
