# 부록 D 용어 사전

요금제: Pro로 충분

[그림 D-1: 낯선 말을 일상 물건에 빗대는 비유]

책에 나오는 기술 용어를 한 줄씩 풀었습니다. 낯선 말이 나오면 여기서 찾아보세요.

읽는 법
- 용어 뒤 괄호의 숫자는 그 말이 이 책에서 처음 나온 장입니다. 본격적으로 다루는 장은 그 뒤일 수 있어요.
- 가나다순 목록과 영문·기호 목록을 나눴습니다. 영문은 알파벳순이고, 점(.)이나 슬래시(/)로 시작하는 것은 맨 뒤에 있습니다.
- 처음 나온 곳에서 풀어 쓴 말과 여기 풀이는 같은 뜻입니다. 다르게 보이면 저장소(부록 A)의 최신 풀이가 맞습니다.
- 책에서 한 번도 안 나온 말은 넣지 않았습니다. 이 사전은 0~58장 원고를 기준으로 만들었습니다.

비유로 외우는 서비스 구조
- 프론트엔드는 손님이 앉는 홀입니다.
- API는 주문을 전달하는 종업원입니다.
- 백엔드는 주문을 받아 요리하는 주방입니다.
- 데이터베이스는 식재료 창고입니다.
- 빌드는 가게 공사, 호스팅은 24시간 문을 여는 일, 도메인은 가게 주소 이름입니다.

새 말이 생기면
- 이 사전은 체크리스트 저장소(부록 A)에서 계속 갱신합니다.
- 용어와 풀이는 한 줄로, 처음 나온 장 번호와 함께 추가합니다.

## 가나다순

- **가맹점 심사**: 결제 서비스가 내 사업자 정보와 파는 물건을 보고 결제를 열어 줄지 정하는 심사. (37장)
- **가상 서버**: 큰 컴퓨터 한 대를 쪼개 나만 쓰게 빌려 준 서버. (28장)
- **가짜 응답(mock)**: 진짜 서버 대신 미리 정해 둔 답을 돌려주는 것. 테스트에서 바깥 서비스를 흉내 낼 때 씁니다. (15장)
- **개발 빌드**: Expo Go가 아니라 내 앱 전용으로 만든 테스트용 앱. (34장)
- **개발용 DB**: 마음껏 부수고 지워도 되는 연습용 데이터베이스. 가짜 데이터만 넣습니다. (12장)
- **개발자 계정**: 스토어에 앱을 올리려고 만드는 계정. 애플은 연 99달러, 구글 플레이는 일회성 25달러입니다. (11장)
- **개인정보처리방침**: 서비스가 어떤 개인정보를 왜 모으고 어떻게 쓰는지 밝히는 문서. 스토어 심사에도 주소가 필요합니다. (7장)
- **거절 사유**: 스토어 심사가 앱을 돌려보낼 때 적어 주는 이유. (23장)
- **검색 엔진**: 구글이나 네이버처럼 웹 글을 모아 두었다가 검색어에 맞는 것을 찾아 주는 서비스. (29장)
- **게임 엔진**: 그리기·입력·물리·소리처럼 게임에 늘 필요한 부분을 미리 만들어 둔 틀. Unity, Godot, Phaser 등. (11장)
- **결정(위키)**: 위키에서 우리가 정한 것을 담는 서랍. 남의 프로젝트에도 참인 사실은 지식 서랍에 둡니다. (56장)
- **겸업 금지**: 다니는 회사가 본업 말고 다른 일을 하지 못하게 하거나 허가를 받게 하는 규정. 근로계약서와 취업규칙에서 확인합니다. (58장)
- **경업 금지**: 다니는 회사와 같은 업종의 일을 따로 하지 못하게 하는 규정. (58장)
- **계획 모드(plan mode)**: 클로드가 파일을 고치기 전에 계획부터 보여 주고 승인을 받게 하는 모드. Shift+Tab으로 켭니다. (9장)
- **결정적(deterministic) 코드**: 같은 입력이면 언제나 같은 결과가 나오는 코드. LLM과 달리 흔들리지 않습니다. (16장)
- **결제 승인**: 고객이 낸 결제를 서버가 마지막으로 확정하는 단계. 승인 전에는 결제가 끝난 것이 아닙니다. (37장)
- **공개 키(publishable key)**: 브라우저에 내려가도 되는 열쇠. 권한은 RLS 같은 규칙으로 따로 막습니다. (27장)
- **공공데이터포털**: 정부와 공공기관의 데이터를 내려받거나 API로 받을 수 있는 사이트(data.go.kr). (0장)
- **공유 범위**: 아티팩트 링크를 누가 열 수 있는지 정하는 설정. 기본은 나만 보기입니다. (1장)
- **광고 단위**: 광고가 나올 자리 하나를 가리키는 이름표(ID). (38장)
- **교정 말**: 클로드가 잘못 알아들었을 때 내가 고쳐 말한 문장. 세션 기록에서 모아 규칙으로 바꿉니다. (57장)
- **교차 검토**: 한 도구가 만든 것을 다른 도구가 다시 검토하는 방식. (45장)
- **구조화 데이터**: 검색엔진이 페이지 내용을 이해하도록 정해진 형식으로 적어 둔 정보(예: JSON-LD). (32장)
- **권한 프롬프트**: 클로드 코드가 무언가 하기 전에 "해도 되나요?" 하고 묻는 창. (2장)
- **규격**: 서로 맞추기로 한 약속. (7장)
- **네임서버**: 내 도메인의 DNS 레코드를 실제로 갖고 있는 서버. (30장)
- **단위 테스트**: 함수 하나처럼 작은 조각이 맞게 동작하는지 따로 확인하는 테스트. (16장)
- **대체 텍스트(alt)**: 이미지를 볼 수 없을 때 대신 읽히는 설명. 검색엔진과 화면 낭독기가 씁니다. (29장)
- **데이터베이스(DB)**: 정보를 표처럼 저장해 두고 꺼내 쓰는 곳. 파일에 그냥 적는 것보다 찾고 고치기 쉽습니다. (0장)
- **데이터 보안 양식**: 구글 플레이 콘솔에서 앱이 어떤 데이터를 모으는지 밝히는 설문. (24장)
- **데이터 스트림**: GA4에서 웹사이트나 앱 하나의 방문 데이터를 받는 통로. (34장)
- **도메인**: `example.com` 같은 사이트 주소 이름. 보통 연 단위로 사서 씁니다. (0장)
- **동의 메시지**: 광고에 쓰이는 개인정보 사용을 사용자에게 묻는 창. (38장)
- **되돌리기(rewind)**: 코드와 대화를 이전 시점으로 되돌리는 클로드 코드 기능. Git보다 약한 안전장치입니다. (2장)
- **등록기관(레지스트라)**: 도메인을 팔고 내 이름으로 등록해 주는 회사. (30장)
- **디자인 시스템**: 색·글꼴·간격 같은 화면의 약속을 한 장에 모아 둔 것. 화면마다 흔들리지 않게 합니다. (1장)
- **디자인 토큰**: 색·간격 같은 디자인 값에 이름을 붙여 모아 둔 것. 여기서 "토큰"은 AI의 토큰과 다른 말입니다. (14장)
- **딥링크**: 앱 안의 특정 화면으로 바로 들어가는 링크. (33장)
- **라이브러리**: 남이 만들어 둔 코드 모음. 가져다 쓰면 처음부터 짜지 않아도 됩니다. (2장)
- **라이선스**: 소프트웨어를 어떤 조건으로 쓸 수 있는지 적은 문서. (6장)
- **랜딩 페이지(소개 페이지)**: 서비스를 처음 보는 사람에게 무엇인지 알려 주는 한 장짜리 웹페이지. (14장)
- **레퍼런스**: 따라 배울 만한 잘 만든 실제 서비스 화면. 구조와 비율만 참고하고 베끼지 않습니다. (1장)
- **로그**: 프로그램이 일한 과정을 시간 순서로 남긴 기록. (12장)
- **로컬**: 내 컴퓨터 안. "로컬에서 돌린다"는 인터넷에 올리기 전 내 컴퓨터에서 해 본다는 뜻입니다. (2장)
- **로컬 서버**: 내 컴퓨터 안에서만 접속되는 작은 웹사이트 운영 프로그램. (2장)
- **루트**: 프로젝트의 가장 바깥 폴더. (4장)
- **루틴**: 정해진 시각에 클로드가 자동으로 하는 일. 클라우드에서 도는 예약입니다. (0장)
- **루프**: 같은 일을 되풀이해서 돌리는 것. (0장)
- **리전(region)**: 클라우드 서비스의 서버가 실제로 있는 지역(예: 서울). 한 곳으로 정해 쓰는 것이 안전합니다. (27장)
- **리치 결과**: 검색 결과에 별점이나 가격 같은 정보가 덧붙어 보이는 모습. (33장)
- **마이그레이션**: 데이터베이스 표 구조를 바꾸는 일, 또는 그 변경을 적어 둔 파일. 기록을 남겨야 되돌릴 수 있습니다. (12장)
- **머지(합치기)**: 다른 브랜치에서 한 작업을 본줄기에 합치는 일. (0장)
- **메타데이터(스토어)**: 이름·설명·키워드·스크린샷 같은 스토어에 올리는 정보. (39장)
- **모델**: 글을 읽고 쓰는 AI 본체. 클로드에는 Haiku, Sonnet, Opus, Fable 같은 등급이 있습니다. (8장)
- **목업**: 실제 화면처럼 꾸민 그림. 눌러 볼 수 있게 만든 시제품은 프로토타입입니다. (1장)
- **무료 티어**: 서비스가 무료로 허락하는 사용 범위. 한도를 넘으면 막히거나 돈이 나갑니다. (19장)
- **무효 트래픽**: 내가 누르거나 기계가 만든 가짜 광고 클릭. 광고 계정이 막힐 수 있습니다. (38장)
- **미니앱**: 이미 큰 앱 안에서 열리는 작은 앱. (11장)
- **미리보기 배포(Preview)**: 본 주소를 건드리지 않고 브랜치마다 따로 만들어 주는 시험용 주소. (25장)
- **민감정보**: 새면 피해가 큰 정보(비밀번호, 주민등록번호, 건강 정보 등). 대화·저장소·위키에 넣지 않습니다. (15장)
- **바이트**: 컴퓨터가 글자를 저장할 때 쓰는 크기 단위. (20장)
- **바인딩**: Cloudflare Workers에서 코드와 DB·저장소를 이름으로 이어 주는 연결. (26장)
- **방어적 파싱**: 필드가 없거나 줄이 깨져도 멈추지 않고 건너뛰며 읽는 방식. 형식이 버전마다 바뀌는 파일을 읽을 때 씁니다. (57장)
- **배포(deploy)**: 만든 것을 인터넷에 올려 다른 사람이 쓸 수 있게 하는 일. (0장)
- **백업**: DB가 날아갈 때 되돌릴 사본. (12장)
- **백엔드**: 손님 눈에 안 보이는 서버 쪽. 주문을 받아 계산하고 처리하는 주방과 같습니다. (11장)
- **버전 코드**: 업데이트를 구분하려고 앱 파일에 붙이는 번호. (24장)
- **버킷**: S3에서 파일을 담는 통. (28장)
- **번들 ID**: 앱 하나를 구별하는 고유 이름(예: com.example.todaymenu). 스토어 값과 코드 값이 같아야 합니다. (23장)
- **베타**: 아직 시험 중인 기능이나 버전. 정식 전에 일부 사람이 먼저 써 보는 것도 베타라고 부릅니다. (1장)
- **보안문자(캡차)**: 사람인지 확인하는 퀴즈. 이 책은 클로드가 대신 푸는 법을 다루지 않습니다. (0장)
- **본인인증**: 내가 나임을 증명하는 절차. 문자 인증번호가 대표적이며 사람이 직접 합니다. (0장)
- **봇 토큰**: 텔레그램 봇을 조종하는 열쇠. 비밀 키처럼 다룹니다. (40장)
- **브라우저 엔진**: 크롬·사파리 같은 브라우저 안에서 웹페이지를 화면에 그려 주는 부분. (11장)
- **브라우저 자동화**: 사람 대신 프로그램이 브라우저 화면을 눌러 일하게 하는 것. (43장)
- **브랜치**: 본줄기에서 갈라져 나온 작업 줄기. 실험을 본줄기와 분리해 둘 때 씁니다. (0장)
- **비결정성**: 같은 질문에도 답이 조금씩 달라지는 LLM의 성질. (15장)
- **비대화형**: 채팅처럼 주고받지 않고 한 번 시켜서 결과만 받고 끝나는 방식. (45장)
- **비밀 키(secret key)**: 서버에서만 써야 하는 열쇠. 코드·저장소·채팅에 절대 넣지 않습니다. (3장)
- **빌드(build)**: 짠 코드를 브라우저나 기기가 읽을 수 있는 파일로 바꾸는 일. (11장)
- **사람 몫**: 로그인·본인인증·문자 인증번호·보안문자·결제·약관 동의처럼 사람이 직접 해야 하는 단계. 클로드는 여기서 멈춥니다. (0장)
- **사업자등록**: 사업을 한다고 국세청에 알리는 절차. 사업 시작 전이나 시작일부터 20일 이내에 신청합니다. (58장)
- **사이트맵**: 사이트의 공개 페이지 주소를 모아 검색엔진에 알려 주는 파일(sitemap.xml). (20장)
- **색인(인덱싱)**: 검색엔진이 페이지를 읽고 검색 결과 후보로 저장해 두는 일. (12장)
- **샌드박스**: 도구가 건드릴 수 있는 범위를 울타리로 막아 둔 안전한 작업 공간. (45장)
- **서명(앱)**: "이 앱은 등록된 개발자가 만들었다"는 도장을 앱 파일에 찍는 일. (23장)
- **서버**: 요청을 받아 답을 돌려주는 컴퓨터 또는 프로그램. (0장)
- **서버 렌더링**: 서버에서 완성된 HTML을 만들어 보내는 방식. 손님에게 완성된 요리를 내오는 가게와 같습니다. (32장)
- **서버리스**: 서버를 없앤다는 뜻이 아니라, 서버 관리를 서비스 회사가 맡는다는 뜻. (26장)
- **서브도메인**: `www.example.com`, `blog.example.com`처럼 도메인 앞에 붙이는 이름. (26장)
- **서브에이전트**: 독립된 대화 공간에서 일하고 요약만 돌려주는 클로드의 도우미. (5장)
- **서비스 계정**: 사람 대신 프로그램이 쓰는 구글 계정. (7장)
- **서치콘솔**: 구글이 내 사이트를 어떻게 보는지 알려 주는 무료 도구(Search Console). (20장)
- **선택자(locator)**: 테스트가 화면에서 버튼·입력칸을 찾는 방법. 역할과 글자로 잡으면 덜 깨집니다. (21장)
