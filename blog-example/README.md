# blog-example

29장의 블로그 뼈대 예시입니다.
실제 블로그는 이 폴더가 아니라 별도 저장소 `<내-계정>.github.io`(공개)에 만듭니다.
이 폴더의 파일을 그 저장소 맨 위에 복사해서 시작하세요.

| 파일 | 내용 |
|---|---|
| `_config.yml` | 제목, 설명, 언어(ko) |
| `index.md` | 첫 화면 |
| `_posts/2026-11-01-hello.md` | 첫 글. 파일 이름은 영문 소문자와 하이픈 |

- 글 파일 이름에 한글·공백을 쓰지 않고, 한글 제목은 글 안의 `title`에 둡니다.
- 이미지는 `assets/`에 내용을 알 수 있는 이름으로 두고 대체 텍스트를 답니다. 첫 글이 가리키는 `assets/today-menu-home.png`는 내 화면 캡처로 직접 채웁니다.
- 공개 전에는 저장소 맨 위에서 `python3 scripts/check-blog-post.py _posts`를 돌립니다. (이 점검 스크립트는 today-menu 저장소의 `scripts/` 에 있습니다. 블로그 저장소로 복사해서 쓰세요.)
